# RLHF-数据流图与分布式控制面

RLHF 数据流图把 rollout/奖励/训练串成闭环，分布式控制面协调资源。

## 1. 机制要点

- 数据流图明确各阶段产物与依赖，控制面管放置与同步
- 闭环瓶颈常在 rollout 与权重同步而非训练

## 2. 实验闭环

```bash
python lessons/lesson-27/run.py
python lessons/lesson-27/run_gpu.py
```

- **输入**：固定 Fixture 场景集（可修改阈值/状态/样本观察验收变化）
- **输出**：结构化报告（状态/原因/检查项）与运行产物
- **验收**：数据流图明确各阶段产物与依赖，控制面管放置与同步；闭环瓶颈常在 rollout 与权重同步而非训练

## 3. 判读纪律

- 默认 Fixture/模拟只验证控制逻辑与合同；真实路径（`--real`/GPU）才产生可用于性能或发布结论的测量。
- 前置条件不足时返回 SKIPPED/precondition_failed 并说明原因，不以模拟或 CPU 结果冒充实测。
- 报告区分 PASS/FAIL/SKIPPED 并附原因与证据（trace/快照/哈希）；负例与失败注入对照必做。
