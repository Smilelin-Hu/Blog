# 文本规范化、语言识别与内容边界清洗

规范化与语言识别划清内容边界：统一编码/空白/繁简，识别语言与噪声边界。

## 1. 机制要点

- 规范化顺序影响下游去重与过滤，需固定流水线
- 语言识别与内容边界清洗去除跨语言/模板噪声

## 2. 实验闭环

```bash
python lessons/lesson-08/run.py
python lessons/lesson-08/run_gpu.py
```

- **输入**：固定 Fixture 场景集（可修改阈值/状态/样本观察验收变化）
- **输出**：结构化报告（状态/原因/检查项）与运行产物
- **验收**：规范化顺序影响下游去重与过滤，需固定流水线；语言识别与内容边界清洗去除跨语言/模板噪声

## 3. 判读纪律

- 默认 Fixture/模拟只验证控制逻辑与合同；真实路径（`--real`/GPU）才产生可用于性能或发布结论的测量。
- 前置条件不足时返回 SKIPPED/precondition_failed 并说明原因，不以模拟或 CPU 结果冒充实测。
- 报告区分 PASS/FAIL/SKIPPED 并附原因与证据（trace/快照/哈希）；负例与失败注入对照必做。
