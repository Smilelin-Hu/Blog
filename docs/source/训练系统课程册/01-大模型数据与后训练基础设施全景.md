# 大模型数据与后训练基础设施全景

后训练基础设施的核心是对象合同与血缘闭包：每个数据/模型对象带版本与来源契约，检查点能正反向追溯。

## 1. 机制要点

- 对象合同约束 schema 与版本，血缘闭包保证任一检查点可反查原始来源与配方
- 机制实验只验证对象关系与状态转换，单机模拟不外推集群吞吐

## 2. 实验闭环

```bash
python lessons/lesson-01/run.py
python lessons/lesson-01/run_gpu.py
```

- **输入**：固定 Fixture 场景集（可修改阈值/状态/样本观察验收变化）
- **输出**：结构化报告（状态/原因/检查项）与运行产物
- **验收**：对象合同约束 schema 与版本，血缘闭包保证任一检查点可反查原始来源与配方；机制实验只验证对象关系与状态转换，单机模拟不外推集群吞吐

## 3. 判读纪律

- 默认 Fixture/模拟只验证控制逻辑与合同；真实路径（`--real`/GPU）才产生可用于性能或发布结论的测量。
- 前置条件不足时返回 SKIPPED/precondition_failed 并说明原因，不以模拟或 CPU 结果冒充实测。
- 报告区分 PASS/FAIL/SKIPPED 并附原因与证据（trace/快照/哈希）；负例与失败注入对照必做。
