# 训练数据格式、分片、索引、流式读取与缓存

训练数据格式与分片决定读取效率：容器格式 + 索引 + 流式读取避免小文件与随机 IO。

## 1. 机制要点

- 打包容器（TFRecord/WebDataset 等）+ 索引支持流式顺序读
- 缓存与预取隐藏存储延迟，分片确定性保证可复现

## 2. 实验闭环

```bash
python lessons/lesson-07/run.py
python lessons/lesson-07/run_gpu.py
```

- **输入**：固定 Fixture 场景集（可修改阈值/状态/样本观察验收变化）
- **输出**：结构化报告（状态/原因/检查项）与运行产物
- **验收**：打包容器（TFRecord/WebDataset 等）+ 索引支持流式顺序读；缓存与预取隐藏存储延迟，分片确定性保证可复现

## 3. 判读纪律

- 默认 Fixture/模拟只验证控制逻辑与合同；真实路径（`--real`/GPU）才产生可用于性能或发布结论的测量。
- 前置条件不足时返回 SKIPPED/precondition_failed 并说明原因，不以模拟或 CPU 结果冒充实测。
- 报告区分 PASS/FAIL/SKIPPED 并附原因与证据（trace/快照/哈希）；负例与失败注入对照必做。
