# 精确、模糊、段落与子串去重

去重分精确/模糊/段落/子串四级：MinHash/SimHash/后缀结构各有适用粒度。

## 1. 机制要点

- 精确去重去完全重复，模糊去重去近重复，粒度越细成本越高
- 去重阈值用反例集校准，避免误删相似但不同样本

## 2. 实验闭环

```bash
python lessons/lesson-11/run.py
python lessons/lesson-11/run_gpu.py
```

- **输入**：固定 Fixture 场景集（可修改阈值/状态/样本观察验收变化）
- **输出**：结构化报告（状态/原因/检查项）与运行产物
- **验收**：精确去重去完全重复，模糊去重去近重复，粒度越细成本越高；去重阈值用反例集校准，避免误删相似但不同样本

## 3. 判读纪律

- 默认 Fixture/模拟只验证控制逻辑与合同；真实路径（`--real`/GPU）才产生可用于性能或发布结论的测量。
- 前置条件不足时返回 SKIPPED/precondition_failed 并说明原因，不以模拟或 CPU 结果冒充实测。
- 报告区分 PASS/FAIL/SKIPPED 并附原因与证据（trace/快照/哈希）；负例与失败注入对照必做。
