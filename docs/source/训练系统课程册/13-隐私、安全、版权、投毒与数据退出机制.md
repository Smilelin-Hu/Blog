# 隐私、安全、版权、投毒与数据退出机制

隐私/安全/版权/投毒治理靠识别 + 退出机制：PII 识别、投毒检测、可执行退出。

## 1. 机制要点

- PII/版权识别前置，投毒检测防恶意样本
- 退出机制能定位并移除特定来源/样本，闭环可审计

## 2. 实验闭环

```bash
python lessons/lesson-13/run.py
python lessons/lesson-13/run_gpu.py
```

- **输入**：固定 Fixture 场景集（可修改阈值/状态/样本观察验收变化）
- **输出**：结构化报告（状态/原因/检查项）与运行产物
- **验收**：PII/版权识别前置，投毒检测防恶意样本；退出机制能定位并移除特定来源/样本，闭环可审计

## 3. 判读纪律

- 默认 Fixture/模拟只验证控制逻辑与合同；真实路径（`--real`/GPU）才产生可用于性能或发布结论的测量。
- 前置条件不足时返回 SKIPPED/precondition_failed 并说明原因，不以模拟或 CPU 结果冒充实测。
- 报告区分 PASS/FAIL/SKIPPED 并附原因与证据（trace/快照/哈希）；负例与失败注入对照必做。
