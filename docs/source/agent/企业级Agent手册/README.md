# 企业级 Agent 手册

围绕 Agent 全生命周期（架构、构建、运行、治理、调优、实践）的企业级工程笔记：从「造出智能」到「用好智能」，以 Harness 为工程中心，把概率性的模型能力组织成可稳定交付、可规模化部署、可进入核心业务流程的生产力。主线回应三大挑战——工程化（从概率智能到可靠生产力）、规模化（稳定/安全/性能/成本）、组织化（从 Agent 孤岛到智能组织）。

> 内容整理自开源教程 [aliyun/ai-agent-handbook](https://github.com/aliyun/ai-agent-handbook)，作为参考笔记。
