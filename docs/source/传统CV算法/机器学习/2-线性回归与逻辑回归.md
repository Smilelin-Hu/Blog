# 线性回归与逻辑回归：从拟合到概率

监督学习主要解决回归与分类两大问题。有的算法只能做回归，例如线性回归；有的只能做分类，例如逻辑回归与贝叶斯分类；其余算法往往两件事都能做。把线性回归与逻辑回归放在一起看，正好能看清「同一套线性结构如何支撑两类任务」。

## 1. 线性回归的基本套路

线性回归属于监督学习，流程和监督学习完全一致：给定训练集，学出一个线性函数，再检验这个函数拟合得好不好，最终挑出代价函数最小的那个。

代价函数（cost function）越小，说明回归得越好——和训练集拟合得越紧；最小值为 0，即完全拟合。

### 1.1 单变量与多变量

单变量线性回归的模型就是一条直线：

$$
h_\theta(x) = \theta_0 + \theta_1 x
$$

多变量线性回归把输入扩展成向量：

$$
h_\theta(x) = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_n x_n
$$

多变量回归之前必须先做 **Feature Scaling**：把各个特征标准化，使取值范围大致落在 \(-1 \le x \le 1\) 之间。原因是梯度类方法对特征尺度敏感，量纲差得太多时，收敛会明显变慢甚至来回震荡。

### 1.2 最小二乘法

「最小二乘法」的核心是让所有数据偏差的平方和最小（「平方」在古时称「二乘」）：

$$
\sum_{i=1}^{n}\left(y_i - \sum_{j=0}^{p} w_j x_{ij}\right)^2
$$

平方而不是绝对值，好处是处处可导、有解析解；代价是对离群点非常敏感。

### 1.3 岭回归

直接用最小二乘，效果取决于样本数 \(n\) 与特征数 \(p\) 的关系：

- \(n \gg p\)：最小二乘回归会有较小的方差；
- \(n \approx p\)：容易产生过拟合；
- \(n \ll p\)：最小二乘回归得不到有意义的结果。

岭回归（Ridge Regression）在平方误差的基础上加一个正则项：

$$
\sum_{i=1}^{n}\left(y_i - \sum_{j=0}^{p} w_j x_{ij}\right)^2 + \lambda\sum_{j=0}^{p} w_j^2,\quad \lambda > 0
$$

调节 \(\lambda\) 就能在方差与偏差之间取得平衡。岭回归优于最小二乘的原因正在于此：随着 \(\lambda\) 增大，模型方差减小、偏差（轻微）增加。这就是经典的方差—偏倚权衡。

岭回归有个明确缺点：建模时同时引入 \(p\) 个预测变量，罚约束项会把待估系数收缩到接近 0，但并非恰好为 0（除非 \(\lambda\) 趋于无穷）。这对精度影响不大，却让模型解释变得困难——岭回归降低了复杂度，却没有真正解决变量选择问题。

### 1.4 Lasso

Lasso 在 RSS（残差平方和）最小化的基础上加入 \(l_1\) 范数作为罚约束：

$$
\sum_{i=1}^{n}\left(y_i - \beta_0 - \sum_{j=1}^{p}\beta_j x_{ij}\right)^2 + \lambda\sum_{j=1}^{p}|\beta_j| = \mathrm{RSS} + \lambda\sum_{j=1}^{p}|\beta_j|
$$

\(l_1\) 范数的关键好处是：当 \(\lambda\) 充分大时，可以把某些待估系数**精确地收缩到 0**，于是 Lasso 天然完成了变量选择——这也是它比岭回归更容易解释的地方。

## 2. 逻辑回归

逻辑回归同样建立在「特征的线性组合」上，只是把输出再过一层逻辑函数。这里用的是 Sigmoid。

### 2.1 从线性输出到概率

样本为 \(\{x, y\}\)，\(y\) 取 0 或 1 表示负类与正类，\(x\) 是 \(m\) 维特征向量。样本 \(x\) 属于正类的概率写成：

$$
p(y=1 \mid x;\theta) = \sigma(\theta^\top x) = \frac{1}{1 + \exp(-\theta^\top x)}
$$

\(\theta\) 是模型参数（回归系数），\(\sigma\) 是 Sigmoid。它由一个更朴素的量变换而来——对数几率，即「属于正类与属于负类的可能性之比」取对数：

$$
\mathrm{logit}(x) = \ln\frac{P(y=1\mid x)}{P(y=0\mid x)}
= \ln\frac{P(y=1\mid x)}{1 - P(y=1\mid x)}
= \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_m x_m
$$

所以逻辑回归就是一个被 logistic 方程归一化的线性回归，仅此而已。它与线性回归的差别在于：线性回归输出可以取到负无穷到正无穷，而逻辑回归把结果压到 0 和 1 之间，这样输出值才能被当作「可能性」来解释。压缩还有额外收益——特别冒尖的变量影响被削弱。

对二分类来说，判定规则很简单：正类概率大于 0.5 就判为正类，否则判为负类。

### 2.2 代价函数：最大似然

假设有 \(n\) 个独立的训练样本 \(\{(x_1,y_1), (x_2,y_2), \ldots, (x_n,y_n)\}\)，\(y \in \{0,1\}\)。单个样本出现的概率可以统一写成：

$$
P(y_i, x_i) = P(y_i=1\mid x_i)^{y_i}\left(1 - P(y_i=1\mid x_i)\right)^{1-y_i}
$$

这个式子的巧妙之处：\(y=1\) 时后一项消失，只剩「属于 1 类的概率」；\(y=0\) 时前一项消失，只剩「属于 0 类的概率」。因此无论标签是 0 还是 1，得到的都是 \((x,y)\) 出现的概率。

整个样本集是独立的，所以总概率是各自相乘：

$$
L(\theta) = \prod_{i=1}^{n} P(y_i=1\mid x_i)^{y_i}\left(1 - P(y_i=1\mid x_i)\right)^{1-y_i}
$$

令似然函数最大的参数 \(\theta^\ast\) 即为所求，这就是最大似然法——似然函数本身就是代价函数。

代价函数有了，下一步是优化。先试求导找解析解：取自然对数再化简，令 \(p_i = P(y_i=1\mid x_i)\)，可得

$$
\begin{aligned}
L(\theta) &= \sum_{i=1}^{n} y_i \log p_i + (1-y_i)\log(1-p_i) \\
&= \sum_{i=1}^{n} y_i(\theta_0 + \theta_1 x_1 + \cdots + \theta_m x_m) - \sum_{i=1}^{n}\log\left(1 + e^{\theta^\top x_i}\right) \\
&= \sum_{i=1}^{n} y_i(\theta^\top x_i) - \sum_{i=1}^{n}\log\left(1+e^{\theta^\top x_i}\right)
\end{aligned}
$$

再对 \(\theta\) 求导：

$$
\frac{\partial L(\theta)}{\partial \theta}
= \sum_{i=1}^{n} y_i x_i - \sum_{i=1}^{n}\frac{e^{\theta^\top x_i}}{1+e^{\theta^\top x_i}}x_i
= \sum_{i=1}^{n}\left(y_i - \sigma(\theta^\top x_i)\right)x_i
$$

令导数为 0 会发现它**无法解析求解**——于是只能迭代，用梯度下降即可。这个梯度形式也解释了逻辑回归为何好训练：误差 \((y_i - \hat{y}_i)\) 乘以特征 \(x_i\)，与线性回归的梯度结构完全一致。

## 3. 两个模型的分工

| 维度 | 线性回归 | 逻辑回归 |
|---|---|---|
| 任务 | 回归 | 分类（二分类 / 多分类） |
| 输出 | 实数，无界 | 概率，\((0,1)\) |
| 假设 | 误差服从正态分布 | 后验概率服从 logistic 分布 |
| 求解 | 最小二乘有解析解 | 最大似然无解析解，需迭代 |
| 正则 | 岭回归（\(l_2\)）、Lasso（\(l_1\)） | 同样可加 \(l_1\)/\(l_2\) 罚项 |

## 写在最后

线性模型的价值在于「可解释 + 快」：参数直接对应特征权重，解释成本极低。但现实数据的特征之间存在非线性关联，纯线性结构力有未逮。下一篇转向一个完全不同的建模视角——贝叶斯分类，它把分类问题重写成「条件概率谁更大」的比较。
