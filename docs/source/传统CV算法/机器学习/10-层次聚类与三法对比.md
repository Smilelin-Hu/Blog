# 层次聚类与三种聚类方法对比

不管是 GMM 还是 k-Means，都面临同一个问题：k 的个数怎么选？在 bag-of-words 模型里用 k-Means 训练码书，究竟该选多少个码字？为了不在这个参数上耗费太多时间，可以考虑层次聚类——它不需要预先指定簇数。

## 1. 算法流程

假设有 N 个待聚类的样本，层次聚类的基本步骤是：

1. **初始化**：把每个样本归为一类，计算每两个类之间的距离，也就是样本与样本之间的相似度；
2. 寻找各个类之间最近的两个类，把它们归为一类（类的总数减少一个）；
3. 重新计算新生成的这个类与各个旧类之间的相似度；
4. 重复第 2、3 步，直到所有样本点都归为一类，结束。

整个过程实际上建立了一棵树。建立过程中可以在第二步设一个阈值：当最近的两个类之间的距离大于该阈值时，认为迭代可以终止。关键的一步是第三步——**如何判断两个类之间的相似度**，这有不少种方法。

## 2. 类间相似度的四种定义

**Single Linkage**（nearest-neighbor）：取两个类中距离最近的两个样本的距离作为两个集合的距离——最近样本越近，两类相似度越大。它容易造成 **Chaining** 效果：两个 cluster 从「大局」上离得比较远，但因为个别点距离较近就被合并，而且合并之后 Chaining 效应会进一步扩大，最后得到比较松散的 cluster。

**Complete Linkage**：完全是 Single Linkage 的反面极端，取两个集合中距离最远的两个点的距离作为两个集合的距离。效果也相反——限制非常大。两个 cluster 即使已经很接近，只要有不配合的点存在，就顽固到底、老死不相合并，同样不是好办法。

这两种定义的共同问题是：只考虑了某个有特点的数据，而没有考虑类内数据的整体特点。

**Average-linkage**：把两个集合中的点两两的距离全部算出来求平均，结果相对合适一些。一个变种是取两两距离的**中值**，相比取均值更能抵抗个别偏离样本的干扰。

**Centroid linkage**：定义类间距离为类间质心的距离，质心是类中所有成员原始数据的均值。

（图 1 里还给出了 Ward's method：它不直接定义类间距离，而是考察「合并这两个簇会让总距离增加多少」，以此决定是否合并。）

## 3. 自下而上与自顶而下

上面介绍的这类方法叫 **agglomerative hierarchical clustering**（自下而上）：描述简单，但计算复杂度高——为了寻找距离最近/最远和均值，需要对所有距离计算个遍，用到双重循环；而且每次迭代只能合并两个子类，非常慢。

另一种叫 **divisive hierarchical clustering**（自顶而下），过程恰好相反：一开始把所有样本归为一类，然后逐步划分为更小的单元，直到每个样本都成为一类。迭代过程中对划分定义一个「松散度」，当松散度最小的那个类的结果都小于阈值时，认为划分可以终止。这种方法用得不太普遍。

## 4. 三种方法对比

### 4.1 K-means

**优点**：简单，时间复杂度、空间复杂度都低。

**缺点**：随机初始化的中心点对结果影响很大；扛不住簇之间 size 或密度差别较大的情况——因为目标函数是距离和，最后必然出来一种「平均主义」的结果。

  <p>图 3：三团大小差异明显时，k-Means 会把大簇切开去「配平」小簇</p>
</div>

  <p>图 4：密度差异明显时，稀疏簇会被邻近的稠密簇吞并</p>

这两张图值得记住：k-Means 的失败不是「参数没调好」，而是目标函数决定的——它只看距离和，不关心簇的形状、大小与密度。

### 4.2 层次聚类

**优点**：可解释性好（例如需要创建一种分类法时）；有研究表明这类算法能产生高质量的聚类，也会用在「先用较大的 K 跑 k-Means，再用层次聚类合并」的阶段；对 k-Means 无法解决的非球形簇也能处理（见图 2）。

**缺点**：时间复杂度高，\(O(m^3)\)，改进后的算法也有 \(O(m^2\lg m)\)，\(m\) 为点的个数；贪心算法一步错、步步错；和 k-Means 一样，难以处理大小不同、凸形的簇。

### 4.3 高斯混合模型

**优点**：投影后样本点不是得到确定的分类标记，而是得到每个类的概率，这是重要信息。

**缺点**：每一步迭代计算量较大，大于 k-Means；求解基于 EM，可能陷入局部极值，且与初始值选取高度相关。

### 4.4 一张表看清分工

| 方法 | 是否需要预设 K | 簇形状假设 | 输出 | 复杂度 |
|---|---|---|---|---|
| k-Means | 需要 | 凸、近似球形 | 硬标签 | \(O(mnK)\) |
| 层次聚类 | 不需要（用阈值切树） | 较灵活，可处理非凸 | 树状结构 + 硬标签 | \(O(m^3)\) |
| GMM | 需要 | 高斯椭圆 | 软概率 | 每轮 \(O(mnK)\) |

## 写在最后

到这一篇为止，聚类的主线已经走完：k-Means 快但假设强，GMM 概率化但依赖初值，层次聚类不预设 K 但代价高。接下来进入一个更现实的前提——数据只有少量标注，其余都没有，这引出半监督学习。
