# K 近邻：只靠邻居投票的分类器

K 最近邻（k-Nearest Neighbor, KNN）是一个理论上比较成熟、实践中最简单的方法之一。它的思路一句话就能说完：如果一个样本在特征空间中的 k 个最相似（最邻近）样本中的大多数属于某个类别，那么这个样本也属于该类别。

KNN 里被选中的邻居都是已经正确分类的对象，所以它在定类决策上只依据最邻近的一个或几个样本来决定待分样本的类别。

## 1. 为什么它能工作

KNN 方法从原理上说也依赖极限定理，但在类别决策时只与极少量的相邻样本有关。由于它主要靠周围有限的邻近样本，而不是靠判别类域的方法来确定类别，因此对**类域交叉或重叠较多**的待分样本集，KNN 比其他方法更合适。

KNN 不仅能分类，也能回归：找出一个样本的 k 个最近邻居，把这些邻居属性的平均值赋给该样本，就得到该样本的属性值。更进一步的做法是按距离加权——距离越近的邻居权重越大，例如权重与距离成正比。

## 2. 算法步骤

一次完整的 KNN 分类可以写成如下流程（用「维护最大距离」的方式避免每次都全排序）：

1. 初始化距离为最大值；
2. 计算未知样本和每个训练样本的距离 `dist`；
3. 得到目前 K 个最近邻样本中的最大距离 `maxdist`；
4. 若 `dist` 小于 `maxdist`，则将该训练样本纳入 K-最近邻集合（并挤掉原来最远的那个）；
5. 重复步骤 2、3、4，直到未知样本和所有训练样本的距离都算完；
6. 统计 K-最近邻样本中每个类标号出现的次数；
7. 选择出现频率最大的类标号作为未知样本的类标号。

这套流程的复杂度瓶颈在第 2、5 步：对每一个待分类样本，都要计算它到全体已知样本的距离。

## 3. 两个必须知道的短板

### 3.1 样本不平衡

当样本不平衡时——某一类样本容量很大、其他类很小——输入一个新样本，它的 K 个邻居中大容量类的样本会占多数，导致误判。

需要注意：该算法只计算「最近的」邻居样本。某一类样本数量很大，并不意味着这类样本一定接近目标样本，数量本身也不能直接影响运行结果。改进办法是加权：距离越近的邻居权重越大。

### 3.2 计算量大

因为对每一个待分类样本都要算它到全体已知样本的距离，才能求出 K 个最近邻点，KNN 的推理成本随样本量线性增长。常用的缓解办法是事先对已知样本点做剪辑，去除对分类作用不大的样本。

这条性质也决定了适用边界：KNN 比较适合样本容量较大的类域自动分类，而样本容量较小的类域用这类方法容易误分。

## 4. 一句直观的总结

KNN 可以看成：有一堆已经知道分类的数据，新数据进来时，先跟训练数据里的每个点求距离，挑出最近的 K 个点，看这些点属于什么类型，再按少数服从多数的原则给新数据归类。
