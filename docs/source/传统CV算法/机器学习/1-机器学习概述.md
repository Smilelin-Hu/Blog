# 机器学习概述：定义、四类范式与典型应用

机器学习是计算机视觉的地基之一。边缘检测、特征提取这些规则明确的任务可以手写算子，但「这张图里是什么」「这个样本属于哪一类」这类问题很难用固定规则描述，只能让程序从数据里自己找规律——这就是机器学习要处理的部分。

## 1. 机器学习与计算机视觉的关系

机器学习完全可以看作一个独立的学科分支。它与计算机视觉有交集，但覆盖面更广：数据挖掘、自然语言处理、生物特征识别、搜索引擎、医学诊断、信用卡欺诈检测、证券市场分析、DNA 序列测序、语音与手写识别、战略游戏、机器人控制，背后都有它的身影。

因此，完整的机器学习体系需要专门的教材支撑，一本以视觉为主线的笔记不可能讲全。这里的取舍是：只提炼对计算机视觉真正重要的那批算法，并把它们在视觉任务里的用法讲清楚。

## 2. 定义：以归纳为主，而非演绎

机器学习（Machine Learning, ML）是一门多领域交叉学科，涉及概率论、统计学、逼近论、凸分析、算法复杂度理论等。它研究的是计算机如何模拟或实现人类的学习行为，以获取新的知识或技能，并重新组织已有的知识结构、不断改善自身性能。

它是人工智能的核心，也是让计算机具备智能的根本途径。与传统的「规则 + 演绎」不同，机器学习主要走**归纳**与**综合**的路线：从大量样本中总结出一般规律，再用这个规律去判断没见过的新样本。

## 3. 发展史：四个阶段

机器学习是人工智能中相对年轻的分支，发展过程大致可分成四段：

| 阶段 | 时间 | 状态 |
|---|---|---|
| 第一阶段 | 20 世纪 50 年代中叶 — 60 年代中叶 | 热烈时期 |
| 第二阶段 | 20 世纪 60 年代中叶 — 70 年代中叶 | 冷静时期 |
| 第三阶段 | 20 世纪 70 年代中叶 — 80 年代中叶 | 复兴时期 |
| 第四阶段 | 1986 年至今 | 最新阶段 |

## 4. 按学习方式分四类

建模方式取决于数据类型，但在动手之前，先确定「算法按什么方式学习」是最有价值的一步——它能帮助根据输入数据的形态，挑到最合适的算法。

### 4.1 监督式学习

输入数据被称为「训练数据」，每组训练数据都带有明确的标识或结果，例如垃圾邮件系统里的「垃圾邮件 / 非垃圾邮件」，手写数字识别里的「1」「2」「3」「4」。

建模时，监督式学习建立的是一个学习过程：把预测结果与训练数据的实际结果比较，不断调整模型，直到预测达到预期的准确率。典型场景是分类与回归，常见算法包括决策树（ID3、C4.5 等）、朴素贝叶斯分类、最小二乘回归、逻辑回归、支持向量机、集成方法，以及反向传播神经网络。

### 4.2 非监督式学习

数据不带特别标识，学习模型的目标是推断出数据的内在结构。常见场景是关联规则学习与聚类，常见算法包括奇异值分解、主成分分析、独立成分分析、Apriori 与 k-Means。

### 4.3 半监督式学习

输入数据一部分有标识、一部分没有。模型需要先学习数据的内在结构，以便合理地组织数据，再做预测。应用场景同样覆盖分类与回归，算法多是对常用监督式算法的延伸：先对未标识数据建模，再对已标识数据做预测，例如图论推理（Graph Inference）、拉普拉斯支持向量机（Laplacian SVM）。

### 4.4 强化学习

输入数据直接作为对模型的反馈。与监督学习不同——监督学习里输入只是「检查对错」的依据，而强化学习里反馈会立刻要求模型调整。常见场景是动态系统与机器人控制，常见算法有 Q-Learning、时间差分学习（Temporal Difference Learning）。

在企业数据应用中，最常用的其实是监督式与非监督式模型。图像识别领域因为「大量无标识数据 + 少量可标识数据」的现实，半监督式学习一直是热点；强化学习则更多落在机器人控制与其他需要系统决策的领域。

## 6. 典型应用与对应算法

| 应用场景 | 关键任务 | 常用算法 |
|---|---|---|
| 购物篮分析（纸尿布与啤酒） | 关联规则 | Apriori |
| 用户细分与精准营销 | 聚类 | k-Means |
| 垃圾邮件过滤 | 分类 | 朴素贝叶斯 |
| 信用卡欺诈检测 | 分类 | 决策树 |
| 互联网广告 | CTR 预估 | 逻辑回归 / 特征交叉模型 |
| 推荐系统 | 协同过滤 | 矩阵分解、近邻方法 |
| 自然语言处理 | 情感分析、实体识别 | 序列模型 |
| 图像识别 | 分类与检测 | 深度学习 |
| 语音识别、人脸识别 | 分类与序列建模 | 深度网络 |
| 个性化医疗、自动驾驶 | 决策与控制 | 强化学习 |
