# 课程导读

## 1. 课程定位

这是一门面向 AI 平台工程师、基础设施工程师、SRE 和技术负责人的系统课程。它从 GPU 资源底座出发，依次建立队列与调度、分布式工作负载、模型交付、可观测性、安全、FinOps 和多集群自助服务能力。

需要具备 Linux、容器、Python 和 Kubernetes 基础。没有可用 GPU 或 Kubernetes 集群时，可以先运行确定性模拟；真实硬件和真实控制面的验证会明确列出环境要求，条件不满足时保持 SKIPPED，不以模拟结果冒充真实结论。

## 2. 学习方式

建议按编号顺序阅读。每篇先理解机制、状态和失败边界，再运行模拟实验，最后在隔离环境执行真实路径。每个阶段结束后回看验收标准与故障诊断；六个综合项目用于把单项能力连接成可运行的平台闭环。
