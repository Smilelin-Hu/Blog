# 多租户 GPU 批处理与配额平台

本项目把前序调度器与碎片、Gang 原子准入、Kueue、Volcano、拓扑感知、弹性容量与 Slurm 协同几篇组合成一套可运行的多租户 GPU 批处理控制面。工程目标是让分布式作业在租户身份、队列配额、Gang 原子性、资源画像和拓扑约束同时满足时启动，并让借用、回收、抢占、碎片、等待与成本归属都能解释。

![多租户 GPU 批处理与配额平台](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiinfra_y4_l32_01.png)

参考场景包含两个租户、四台八卡节点、四个工作负载和十七类反例。模拟只验证控制合同与指标计算，不证明真实 Kueue、Volcano、Slurm、GPU 拓扑或抢占性能。真实集群缺失时必须返回 SKIPPED。

## 1. 工程目标

交付结果必须满足四项核心验收：Gang 作业不会部分占卡；借用与回收行为有 Owner、范围和 Reason；拓扑约束从准入到 Pod 位置可以验证；租户配额身份与成本标签使用同一稳定目录。进一步用等待、准入率、公平偏差、碎片率和抢占恢复时间量化运营状态。
