# LLM 评测体系与基准工程：能力、安全、幻觉与评测 Harness

12 篇第 8 节做基准去污染、33 篇第 9 节是代理训练评测、主题三 10 篇第 5 节是性能评测矩阵；本文补「模型质量评测」的方法学与 harness 工程。与主题三 29 篇第 6 节的分界先划清：**本文管离线基准（可复现的横向比较），29 篇第 6 节管在线门禁（生产流量的质量回归）**，两者共用评测集与 judge 校准产物。没有可信的离线基准，后训练所有配方结论都不可证伪。

## 1. 评测分层与基准选型

| 层 | 代表基准 | 测什么 | 已知陷阱 |
|---|---|---|---|
| 知识与推理 | MMLU(-Pro)、GPQA、BBH | 学科知识、研究生级推理 | 饱和、选项偏置、污染 |
| 数学与代码 | GSM8K、MATH、HumanEval、LiveCodeBench、SWE-bench | 可验证答案的能力 | 模板记忆、测试集泄漏 |
| 指令与对话 | IFEval、MT-Bench、AlpacaEval | 约束遵循、对话质量 | judge 偏置、长度偏好 |
| 幻觉与事实 | TruthfulQA、HaluEval、FActScore 类 | 事实性、编造率 | 与「知识不足」难区分 |
| 安全 | 红队越狱集、拒答/过度拒答对照 | 攻击成功率、误拒率 | 攻击集时效性 |

选型纪律：静态基准（MMLU/GSM8K）用于纵向回归但必须配合 12 篇第 8 节的去污染证据；**动态基准**（LiveCodeBench/LiveBench 按时间窗收题）用于横向比较以抗污染；饱和基准（多数模型 >90%）失去区分度，只留作冒烟。基准分数是「在特定 prompt 模板与解码参数下的分数」，脱离配置谈分数无意义。

## 2. Harness 工程：lm-eval 与可复现性

lm-evaluation-harness 是事实标准（HELM 是多指标全景框架的对照）：任务以 YAML 声明（数据集、prompt 模板、few-shot 数、度量），两类执行模式——loglikelihood（选项打分，MMLU 类）与 generate_until（生成后抽取答案，GSM8K 类），模式选错分数不可比。

可复现性五要素全部 pin 版本并随结果存档：**数据集版本、prompt 模板与 few-shot 样本、解码参数（temperature/greedy）、harness 版本、judge 模型版本**。同一模型换 harness 版本或模板，分数漂移可达数个点——跨报告比较前先核对这五项。工程上把评测做成 CI 任务：固定种子、固定 batch、结果落盘带完整配置哈希，任何配方变更（数据/超参/合并）触发同一评测集回归。

## 3. LLM-as-judge：偏置与校准

judge 模型评开放生成是主流做法，但已知偏置必须治理：位置偏置（偏好先出现的答案，用交换顺序双评取一致）、冗长偏置（偏好长答案，AlpacaEval 2 的长度控制回归是标准对策）、自我偏好（judge 偏好同族模型输出，换异族 judge 交叉验证）。

校准流程：抽样人评作为 gold，计算 judge 与人评一致率（Cohen's κ 或 pairwise agreement），一致率不达标的 judge 结论降级为参考；judge 版本进五要素 pin 清单，judge 升级视为评测口径变更需重跑基线。judge 本身也是模型 API 消费，评测预算要计 token 成本（33 的成本口径）。

## 4. 幻觉、安全与领域评测

- 幻觉评测分两类：闭卷事实问答（TruthfulQA 式，测「不知道时是否编造」）与开卷忠实度（FActScore 式，把长答案拆原子事实逐条对证据核验）。后者与 RAG 场景直接相关，原子事实拆解本身可用 judge 但需人评抽检。
- 安全评测与主题三 37 的在线护栏配对：离线红队集测越狱成功率（分攻击家族统计），同时测**过度拒答**——安全对齐把正常请求拒掉的比例，两者要一起报，只报其一都是片面结论。
- 领域评测自建：从生产真实 query 分层抽样构造 golden set（脱敏后），比公开基准更能预测上线表现；构造与更新流程归 29 篇第 6 节的在线门禁闭环。

## 5. 统计纪律与验收

- 小样本基准（几百题）的分数差异必须带置信区间：bootstrap 重采样或配对检验，1–2 个点的「提升」常在噪声内；多基准多模型比较时警惕多重比较（挑最好看的报）。
- 报告规范：分数 + 配置哈希 + 置信区间 + 污染检查结论，缺一项不可作为配方决策依据。
- 验收清单：评测 CI 化（配方变更自动回归）、五要素版本全 pin、judge 与人评一致率达标、动态基准占比满足抗污染要求、安全与过度拒答成对报告、领域 golden set 有更新机制。
