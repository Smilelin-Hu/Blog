# 模型化质量评分、领域分类与难度建模

## 1. 本文要解决的工程问题

质量分类器在训练集上很准，换到另一种语言和领域后却把陌生文体当成低质；团队仍把单一分数当作发布真值。

本文围绕一个可执行判断展开：怎样训练、校准和治理模型化质量、领域与难度评分器？读完应能给出自己的系统边界、输入输出、版本关系和验收证据，而不是只复述工具名称或公式。

## 2. 本文交付物与判定标准

本文的核心决定是：把质量、领域和难度拆成不同任务，保存训练分布、校准曲线、置信区间与拒判状态，并给分布外输入单独门禁。

完成学习和实验后，应当交付一份最小可复现记录，至少包含输入快照、配置、代码版本、运行状态、原始输出和结论边界。验收证据是：分类器按来源、语言、长度和领域切片评估；阈值选择展示精确率、召回率与人工复核成本的取舍。

围绕“模型化质量评分、领域分类与难度建模”的验收不接受三类替代品：把模拟输出写成真实 GPU 结果；只展示成功样本而隐藏失败与 `SKIPPED`；只给总分，不保存能复算总分的对象级记录。

## 3. 前置知识与实验边界

“模型化质量评分、领域分类与难度建模”的机制实验使用 Python 3.10 及以上版本和标准库，重点验证对象、算法或状态转换。真实硬件路径使用 PyTorch；检测不到 CUDA 时必须输出结构化 `SKIPPED`，不得静默改跑 CPU 后仍标成 GPU 实测。

模型化评分是可版本化的代理信号，不能替代许可证、安全检查或下游训练消融。

### 3.1 业务背景与失败模式

启发式规则擅长发现长度异常、符号堆砌和内部重复，却很难判断一篇文章是否解释清晰、属于哪个细分领域、对当前模型是否过易或过难。模型化数据选择把人工判断、教师模型、参考语料、语言模型损失和下游反馈压缩成可扩展预测器，使万亿 Token 语料能够按质量、领域和难度排序。但预测器并不等于真值：它会继承标注标准、教师偏好、参考分布与 Tokenizer 偏差，还可能被模板和对手绕过。

本文从数据产品而非“训练一个分类器”出发，建立 Label Spec、特征与模型 Artifact、校准、拒识、Shadow、推理服务、分布式批处理、影响查询和下游消融的完整闭环。应能理解二分类、序数回归、多标签领域分类、困惑度、损失差、参考分布相似度、学习进度与可学性等信号；能区分文档质量、领域、难度、毒性、许可和重复度；能用 CPU 实验训练可解释小模型，并为通用 CUDA 编写真实 DDP 训练与推理路径，硬件不足时返回 `skipped`。

### 3.2 质量模型

质量模型预测文档相对某个用途的价值，例如教育性、连贯性、事实密度、技术深度或对话帮助度。标签可以是二元、序数或多维。它不能自动代表许可合规、安全无害或真实性。一个高质量的版权受限文本仍不可使用，一篇流畅的错误文章也可能高分。输出应叫 quality_prediction 并绑定 rubric，而不是笼统 gold_score。

### 3.3 领域模型

领域模型描述内容属于哪些主题或文体，例如通用、科学、医学、法律、金融、代码、数学、新闻、论坛和产品。现实文档通常多标签且层级化：一篇用 Python 讲量化金融的教程同时属于代码、金融与教育。强制单标签会损失混合信息。领域标签主要服务分层画像、Mix 约束、路由和评测，不应自动决定质量高低。

### 3.4 难度模型

难度描述对特定模型而言，样本带来多大认知与优化挑战。它不是文本长短，也不等于困惑度。参考模型高损失可能表示难知识、陌生领域、乱码或标签错误；低损失可能表示基础样本、模板重复或已经记忆。难度输出必须绑定 reference model、Tokenizer、上下文构造和时间，不能作为文档永久属性。

### 3.5 三者的联合关系

高难度不等于高质量；低难度也可能有校准价值。

同一文档可以质量高、医学领域、对小模型很难；也可以质量低、通用领域、对模型很容易。数据选择器通常在领域预算内，用质量控制下限，用难度或学习进度安排课程。若先把三者压成单分，后续无法保障领域覆盖，也无法区分“难而有价值”和“难因为损坏”。因此资产层保存独立预测与证据，Mix 层再做用途化组合。

### 3.6 与强制 Policy 的边界

隐私、数据退出、恶意软件和许可属于必须执行的 Policy，不参与模型分数权衡。模型可提供风险候选，但 Policy 决策保留专用状态与原因。不能允许高质量分抵消隐私命中，也不能用低分替代版权审核。控制面先应用强制 Policy，再让合格数据进入质量、领域和难度选择。

### 3.7 二元标签

“适合/不适合目标预训练”易于训练和评估，但把多种原因压在一起。正负样本选择决定模型学到什么：若正例全是百科、负例全是乱码，模型会把百科风格当质量；若负例来自另一个语言，模型可能只学语言。二元标签需附 reason facets 与抽样来源，评估按切片展示，不只报 AUC。

### 3.8 序数标签

教育质量常用 1 到 5 等级，顺序有意义但间距未必相等。把它当普通回归会假设 5 与 4 的差等于 2 与 1；把它当无序分类又浪费顺序。可使用累计链接、多个阈值二分类或序数损失。标签指南需给每级锚点与边界案例，模型输出阈值概率和期望分都可保留。

### 3.9 多维标签

将连贯性、信息密度、事实支持、结构完整、教育价值和任务适配分别标注，能解释不同用途。代价是标注更慢、分歧更多。可让教师先产生结构化理由，人工只复核关键维度。最终不要简单平均；不同 Mix 使用不同权重，并保留每维不确定性。

### 3.10 成对偏好

让标注者比较同领域、相近长度的两个文档，通常比绝对打分稳定。训练可用 Bradley-Terry 形式：

$$P(d_i \succ d_j)=\sigma(s_i-s_j)$$

配对构造必须避免让长度、来源或格式成为捷径。排序分数只在比较分布内有意义，跨语言跨领域需要锚点或独立校准。循环偏好与标注分歧应保留。

### 3.11 教师模型标签

强模型可按 rubric 批量评分并给理由，随后训练轻量分类器扩展到全量。FineWeb-Edu 一类工作展示了这种路线的工程价值，但教师标签会继承模型偏好、提示敏感与知识盲区。必须固定教师版本、prompt、解码参数和输入截断，抽取人工 Gold 评估，并防止学生只学习理由模板或格式特征。

### 3.12 隐式标签

引用、编辑历史、用户停留、课程采用、代码执行或专家来源可以成为弱监督。它们常受曝光、平台与群体偏差影响。应保存 label_source 和 propensity 证据，避免把受欢迎直接等同正确。多个弱信号可用生成模型或置信加权组合，但最终仍需人工和下游验证。

### 3.13 标签版本与不可变性

每条标签绑定 record_id、view_digest、rubric_version、annotator/teacher、prompt、时间与 confidence。指南变化产生新 Label Set，不覆盖旧值。正文修改后旧标签不能自动迁移。训练 Manifest 精确列出使用哪些标签版本，使模型 Artifact 可复现。

## 4. 训练集设计与泄漏控制

### 4.1 正负例的来源匹配

若正例来自书籍、负例来自网页，分类器会学习来源、HTML 残留和长度，而不是质量。更强设计是在同来源、语言、类型和长度桶内比较高低样本，或通过重加权平衡。评估也要包含来源外推集。来源特征可作为诊断，但不应成为无法解释的捷径。

### 4.2 文档去重后再划分

近重复若跨训练与测试，质量指标会虚高。先使用精确、MinHash 或语义簇建立 group_id，再按组划分。教师标签的同模板页面也要 group split。划分 Manifest 保存算法、阈值和 seed。后续新增数据不能仅随机追加到测试，需防止与训练簇重叠。

### 4.3 域级划分

只做随机文档划分无法测新站点泛化。至少同时有 random holdout 和 domain holdout；多语言系统再增加 language holdout 或低资源集。模型可能在随机集 AUC 很高，在新域完全失效。发布门禁按真实部署风险选择最重要的外推集。

### 4.4 时间划分

新术语、站点模板和内容生成方式持续变化。用较新时间窗口做测试能评估时间漂移，避免未来信息进入训练标签。教师模型可能已经见过旧网页，不能证明文本本身质量。时间切片输出单独校准与 coverage-risk。

### 4.5 基准污染

标签集、质量正例、领域词典和难度评估不能包含目标基准原题或近似改写，否则选择器会定向偏好基准风格。建立 benchmark registry 与污染扫描，测试集本身也按权限隔离。选择器评估和最终模型评测使用独立血缘。高分样本若与评测相似，应先进入污染检查。

### 4.6 长度与语言平衡

分类器很容易用长度猜等级，用主流语言字形猜高质量。训练采样在标签内平衡长度与语言，或者显式做条件模型；评估画出各桶可靠性。不能简单全部截成固定长度而丢掉文档后部结构。输入策略可以首尾窗口、多段采样或层级编码，并保存窗口位置。

### 4.7 困难负例

随机乱码负例太容易，无法教模型区分流畅 SEO 文、事实空洞模板、答案缺失和表面专业的错误内容。使用启发式 gray、旧模型高置信错误、人工争议与对抗生成构建困难负例。困难挖掘每轮都要保持固定 Gold，防止训练分布只剩极端边界。

### 4.8 训练样本权重

教师高置信、多人一致和专家标签可高权重；弱监督、单教师与争议样本降权。权重不能只看模型自己的 confidence 形成自确认。记录 weight_reason 并在消融中比较。类别不平衡可用采样或损失权重，二者同时使用需防止过补偿。

## 5. 模型架构选择

### 5.1 线性与 fastText 类模型

字符/词 n-gram 线性模型训练与推理便宜，能在大规模 Token 预筛中发挥作用，且容易查看重要特征。[DCLM](https://arxiv.org/abs/2406.11794) 的公开实验展示了模型化过滤的作用，但模型收益仍取决于正例分布、目标评测与配方。轻量模型可能依赖浅层风格，对语义和长距离结构有限。它适合作为第一阶段排序或教师蒸馏学生。

### 5.2 编码器分类器

小型 Transformer 编码器能建模语义和局部结构，常用于教育质量、领域与安全分类。输入长度限制要求窗口策略。多任务头可共享编码器同时输出质量、领域和难度代理，但任务冲突、标签缺失和校准更复杂。共享模型节省推理成本，资产层仍保存各头独立版本与阈值。

### 5.3 生成式教师

大型生成模型可以遵循复杂 rubric、输出分项与理由，还能对成对文档排序。成本、延迟、提示敏感和不可复现性使其不适合直接全量执行，常用于标注子集、争议仲裁与主动学习。理由可能听起来合理却非真实因果，因此学生训练主要使用结构标签，理由需人工抽检。

### 5.4 参考语料分类器

将高质量目标语料作为正例、Common Crawl 随机样本作为负例，可训练分布相似度分类器。它实际预测“像参考集”，不等同普遍质量。参考集若偏百科或学术，模型会清除口语与长尾。输出名称和数据卡必须说明 reference distribution，Mix 层结合多样性约束使用。

### 5.5 困惑度模型

给定参考 LM，文档平均负对数似然为：

$$L(d)=-\frac{1}{T}\sum_{t=1}^{T}\log p_\theta(x_t|x_{\lt t}),\qquad PPL=e^{L}$$

低损失可能流畅也可能重复，高损失可能难或噪声。应同时记录长度、语言、领域、Tokenizer 覆盖和局部损失分布。参考模型训练数据泄漏会压低已见文本。PPL 只是一种模型相对信号，不是质量温度计。

### 5.6 损失差与 DSIR 思路

比较目标模型与背景模型的文档似然，可估计文本更接近目标域还是通用域。类似地，重要性重采样利用目标与原始分布密度比调整选择。密度比极端时需要裁剪，参考样本决定偏好。它更适合领域适配而非全局质量。估计器、特征与采样权重全部版本化。

### 5.7 集成模型

不同 seed、架构、教师或输入窗口的预测可平均，提高稳定并估计分歧。不应把所有模型相关错误误认为独立不确定性。保存单成员摘要与输出，至少对 gray 样本保留方差。集成成本高，可只用于阈值附近，轻量学生服务全量。

## 6. 领域分类：多标签、层级与开放集合

### 6.1 标签本体

分组划分应阻止近重复与同源样本跨越训练评测边界。

领域树从粗粒度到细粒度，例如 science→biology→genomics。标签应有定义、正反例、父子关系、Owner 和版本。不要让部门组织结构直接成为内容本体。多标签允许交叉领域，标签数需控制，否则标注和评估稀疏。退役标签提供映射但不覆盖历史。

### 6.2 多标签损失

对每个标签 $k$ 使用独立 sigmoid 与二元交叉熵：

$$\mathcal{L}_{domain}=-\sum_k w_k[y_k\log p_k+(1-y_k)\log(1-p_k)]$$

标签缺失不等于负例，需要 mask。稀有标签可使用重加权、焦点损失或分层采样，但要校准概率。父子一致性可通过约束或后处理保证，例如预测 genomics 时 biology 概率不应更低得离谱。

### 6.3 开放集合拒识

生产数据会出现本体之外的新领域。最高 softmax 低只是一个信号，神经模型对域外数据仍可能过度自信。可使用能量、距离、集成分歧与已知类原型，并保留 other/unknown。域外样本进入聚类与人工发现流程，而不是被强制归到最接近标签。

### 6.4 层级评估

预测具体子类错成同父兄弟，与错到完全不同大类的代价不同。除 micro/macro F1，还报告层级距离、父级召回、稀有标签 AP 和多标签校准。按文档长度与混合程度切片。总体 micro F1 会被大类支配，不能作为唯一门禁。

### 6.5 文档级聚合

长文按段落或窗口预测，再按有效 Token、段落类型与置信聚合。一个附录代码块不应把论文主域变代码，一个医学免责声明也不应把普通商品页变医学。保留 window predictions 和聚合权重，误判时能定位。标题可以高权重，但需防 SEO 标题欺骗。

### 6.6 本体漂移

新技术和交叉领域不断出现。监控 unknown、低 margin、聚类新簇和人工“无合适标签”，定期提出本体变更。新标签加入后需要回标代表数据、重新训练并提供旧新映射。不能每月随意改标签含义，让历史 Mix 不可复现。

## 7. 难度建模与可学性

### 7.1 绝对难度不存在

同一微积分教材对通用小模型很难，对数学大模型可能容易。难度资产必须包含 reference_model、Checkpoint、训练历史、Tokenizer 和上下文长度。静态语言复杂度只能描述文本，不等价模型难度。Mix 使用难度时明确目标学生模型阶段。

### 7.2 平均损失与尾部损失

文档平均损失会把少数极难 Token 稀释。保存 P50、P90、P99、最大窗口和高损失 Token 类别，能区分整体陌生与局部乱码。忽略 padding、文档边界和 prompt 模板 Token。对不同长度使用相同定义，并记录截断覆盖。

### 7.3 学习进度

在多个 Checkpoint 计算损失下降：

$$LP(d;t_1,t_2)=L_{t_1}(d)-L_{t_2}(d)$$

下降大表示模型正在学习，始终高可能是太难或噪声，始终低可能已掌握或重复。Checkpoint 必须来自同训练轨迹，随机波动用平滑与重复估计。学习进度是动态信号，不能脱离训练阶段永久保存为“难度”。

### 7.4 忘却与波动

样本损失先降后升可能体现遗忘、冲突或训练噪声。记录时间序列的斜率、方差和反转次数，但数据采样频率不均会偏置。对预训练万亿文档逐条追踪成本高，可在稳定样本或域级聚合。异常簇用于调整课程与混合，而非直接删文档。

### 7.5 梯度代理

梯度范数、影响函数或表示距离可估计样本对优化的作用，但计算昂贵且受模型状态影响。小模型或低秩近似可做实验，结论需下游验证。高梯度可能有信息也可能标签错。生产中更多用于选择子集与困难挖掘，不作为单一硬门禁。

### 7.6 教师评分难度

教师可判断概念先修、推理步数、术语密度和答案可得性，适合 SFT 与推理数据。Prompt 必须区分“内容难”和“写得差”。教师自身在超出知识范围时会误判。用人工锚点校准，并让输出包含维度与不确定性。

### 7.7 课程策略

由易到难并非总最优；多样性、遗忘和任务干扰都会影响。课程可以按训练阶段改变领域×质量×难度权重，保留随机探索。每次调度由 Curriculum Manifest 记录。难度模型输出事实证据，课程控制器做策略，不互相覆盖。

## 8. 校准、阈值与不确定性

### 8.1 为什么分类概率不可信

交叉熵训练模型常过度自信，类别平衡、域漂移和教师噪声都会改变概率含义。AUC 高不表示 0.8 就是八成正确。发布需要可靠性图、Brier score、Expected Calibration Error 和选择性风险。校准集与测试集分开，且代表部署分布。

### 8.2 温度缩放

对 logits $z$ 除以正温度 $T$，在校准集优化 NLL。它简单且保持排序，但不能修复类别条件或域条件偏差。多标签可每类温度或共享温度，稀有类容易过拟合。温度参数与模型 Artifact 绑定，模型权重变化后失效。

### 8.3 等距回归与分桶

Isotonic 能学习单调非参数映射，数据少时会过拟合阶梯；分桶校准易解释但边界敏感。按语言、类型条件校准需要足够支持。可使用全局映射加切片修正。任何校准只承诺在验证范围内，域外样本仍需拒识。

### 8.4 选择性预测

定义 coverage 为自动决定比例，risk 为其中错误率。调整阈值画 coverage-risk 曲线，为高误删成本设置目标风险。accepted 与 rejected 可各有高置信区，中间 gray。总体 coverage 不能掩盖少数语言 risk，关键切片分别设门禁。

### 8.5 不确定性来源

最大类别分数不能自动代表充分证据。

数据噪声属于 aleatoric，模型分歧与域外属于 epistemic，标签指南含糊是规范不确定性。单一 entropy 无法区分。可结合集成方差、教师分歧、标注一致、域距离和输入支持度输出 evidence。动作随来源不同：数据噪声可能隔离，模型未知适合主动学习，规范不明需要改 rubric。
