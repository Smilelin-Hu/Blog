# 领域分类、采样权重与数据课程

## 1. 本文要解决的工程问题

数据团队按库存比例混合领域，业务团队却希望补数学和代码能力；训练越久，库存大的通用网页越占预算，目标能力反而得不到足够更新。

本文围绕一个可执行判断展开：怎样从领域目标、能力覆盖和训练阶段推导可审计的采样权重？读完应能给出自己的系统边界、输入输出、版本关系和验收证据，而不是只复述工具名称或公式。

## 2. 本文交付物与判定标准

本文的核心决定是：从能力目标、数据供给、质量门槛和训练阶段推导采样权重，并把课程顺序与静态混合分开记录。

完成学习和实验后，应当交付一份最小可复现记录，至少包含输入快照、配置、代码版本、运行状态、原始输出和结论边界。验收证据是：每个领域都有目标 Token、实际 Token、重复采样率和下游切片；权重变化能追到配方版本。

围绕“领域分类、采样权重与数据课程”的验收不接受三类替代品：把模拟输出写成真实 GPU 结果；只展示成功样本而隐藏失败与 `SKIPPED`；只给总分，不保存能复算总分的对象级记录。

## 3. 前置知识与实验边界

“领域分类、采样权重与数据课程”的机制实验使用 Python 3.10 及以上版本和标准库，重点验证对象、算法或状态转换。真实硬件路径使用 PyTorch；检测不到 CUDA 时必须输出结构化 `SKIPPED`，不得静默改跑 CPU 后仍标成 GPU 实测。

采样权重决定训练看到什么，不保证模型按相同比例获得能力。

### 3.1 业务背景与失败模式

经过解析、清洗、去重与治理后，团队拥有的仍然只是“可以考虑使用的数据”，而不是一份可直接训练的配方。网页、代码、数学、论文、百科、对话、金融、医疗和多种语言的规模可能相差几个数量级。若按库存比例随机采样，最大来源会支配训练；若把每个领域强行采成相同比例，小而嘈杂的来源会被反复看见，产生过拟合、记忆和能力偏移；若按人的直觉一次性填写权重，训练中模型状态变化后，早期合理的配方可能在后期变得低效。

本文建立从领域定义到训练时采样的完整控制面。核心不是学会调用一个 `WeightedRandomSampler`，而是能回答六个问题：样本究竟属于哪个领域；分类错误如何影响预算；库存比例、目标权重、实际消费量之间是什么关系；怎样给小领域保底而不无限重复；课程学习如何随训练阶段改变数据分布；如何证明训练进程真正消费了计划中的分布。

最终产物是一份可版本化的数据配方。它包括领域本体、分类器及置信度、候选库存、过滤条件、目标 Token 预算、采样策略、课程阶段、随机种子、重复上限、在线计量和验收阈值。配方不复制数据，它像编译计划一样引用不可变数据集，并将业务目标转换为训练器能够执行和审计的选择过程。

### 3.2 学习目标与能力清单

### 2.1 库存分布不是训练目标

设清洗后共有 $K$ 个领域，第 $i$ 个领域有 $N_i$ 个可用 Token，总库存为 $N=\sum_i N_i$。自然库存比例是：

$$q_i=\frac{N_i}{N}$$

如果训练器从全局对象集合均匀抽取 Token，长期消费比例会接近 $q_i$。这个结果只描述数据湖里有什么，不代表产品希望模型学什么。网页通用语料可能占百分之九十，而高质量数学只占千分之一；直接跟随库存会让稀缺能力几乎没有梯度机会。

### 2.2 目标混合是受约束的决策变量

我们定义训练目标比例 $p_i\geq0$，且 $\sum_i p_i=1$。总训练预算为 $B$ 个 Token，则领域预算为 $B_i=p_iB$。选择 $p_i$ 时同时考虑产品能力、验证损失、来源质量、独特 Token、重复风险、许可限制和吞吐成本。它不是一个从数据量唯一推导出的事实，而是一项需要实验验证的决策。

若 $B_i\gt N_i$，意味着该领域至少有部分 Token 会重复。理想化的平均曝光次数为：

$$e_i=\frac{B_i}{N_i}$$

当 $e_i=4$ 时，不能理解为每个文档恰好看四次；真实采样存在方差，热门分片或短文可能更多。工程系统既要报告期望曝光，也要统计记录级与 Token 级的实际曝光分布。

### 2.3 三种分布必须同时保存

长度、拒绝和 Mask 都会改变最后的梯度贡献口径。

配方中至少保存库存分布、计划分布和实现分布。库存分布来自发布快照；计划分布是经审批的 $p_i$；实现分布是训练过程中按 Token 计量的消费结果。只保存权重无法证明实现正确，尤其当序列长度、Packing、坏样本跳过和数据加载器重试会改变实际比例时。

计量应以进入损失计算的有效 Token 为主，同时保留样本数、序列数和原始字节数。不同领域平均文档长度差异很大，按样本数对齐并不等于按 Token 对齐。若训练目标是控制梯度贡献，还要记录 Loss Mask 之后的受监督 Token，不能把模板或填充 Token 算作有效预算。

### 3.3 实验准备与责任边界

### 3.1 领域不是文件夹名

一个网页可能同时是中文、医学、问答体和高质量专业内容。领域至少有四条相互正交的轴：语言与地域、知识主题、内容体裁、来源或质量等级。若强行把它压成单一标签，团队会在“中文医学问答究竟算中文、医学还是对话”上反复争论，并丢失采样需要的信息。

更稳妥的是多轴本体：`language=zh`、`topic=medicine`、`genre=qa`、`quality=tier_a`、`source_family=licensed_forum`。训练配方再通过规则将多轴组合投影为采样桶，例如 `zh_medicine_qa_a`。原始属性长期稳定，桶可以随实验需求重建。

### 3.2 本体要有明确互斥与包含关系

每个轴应说明标签是否互斥、是否允许多标签、父子关系是什么、未知和混合如何表达。语言轴可有主语言和语言片段；主题轴可多标签；质量等级通常需要互斥；来源族来自注册表事实，不应由内容分类器猜测。缺少定义时，不同团队会用同一个标签表达不同含义，历史实验不可比较。

标签文档至少给出正例、反例、边界例和判定顺序。`code` 是只包含源码，还是也包含技术解释？`math` 是含公式就算，还是必须以数学推理为主要目的？这些边界会直接改变权重和预算，不能留给每个处理任务临时发挥。

### 3.3 为未知、混合与冲突留正式位置

分类器置信度不足时输出 `unknown`，多个主题都重要时输出带概率的多标签，来源元数据与内容预测冲突时输出 `conflict` 并保留两者。不要为了让统计图加总到百分之百，就把所有不确定样本硬塞进最接近的桶。

未知率本身是健康指标。突然升高可能意味着出现新领域、解析异常、语言模型失效或上游字段改变。生产配方可给未知桶小额探索预算，也可以先隔离；选择取决于风险，而不是由分类器默认值决定。

### 3.4 本体演进需要版本和迁移

强制塞入已知域会隐藏分类不确定性。

当团队拆分 `science` 为物理、化学和生物时，旧快照不能被静默重标。应发布本体新版本，固定分类器与规则，对历史候选集执行可重放迁移，并输出旧桶到新桶的流量矩阵。训练运行继续引用当时版本，新实验才使用新版。

若只修改标签名称却不记录迁移，指标趋势会产生假变化。领域能力提升可能只是桶定义变窄，某来源占比下降也可能只是标签移动。版本化使团队能区分数据变化、分类器变化和定义变化。

## 4. 领域分类流水线

### 4.1 先使用可靠元数据

来源合同、站点栏目、仓库语言、出版物分类和人工标注常常比正文分类更可靠。分类流水线先验证这些元数据的来源与版本，再把它们作为特征或高置信规则。不能把 URL 中出现 `medical` 就无条件认定为医疗，因为站点模板、镜像和垃圾页面会制造大量误判。

元数据规则需要监控覆盖率和冲突率。可靠元数据只覆盖一部分对象时，剩余对象进入内容分类器。二者冲突时不要简单以任一方覆盖，保留冲突样本供抽查，才能发现来源注册错误或分类器概念漂移。

### 4.2 轻量规则负责高精度区域

文件扩展名、代码解析成功、数学符号密度、对话角色结构和出版物标准标识可以形成高精度规则。规则优点是便宜、可解释、可在大规模 CPU 流水线运行；缺点是覆盖有限，并会被模板和格式变化欺骗。

规则输出包含标签、置信度、证据和规则版本。例如 `genre=code` 的证据不是“出现大括号”，而是“解析器识别为 Python 并成功生成 AST，代码字符占正文百分之八十”。强证据可以直接定类，弱证据只进入模型特征。

### 4.3 监督分类器扩展覆盖

训练集应从真实候选池分层抽样，覆盖长尾来源、混合文本、短文本和困难边界。随机抽取大量主流网页会得到很高的总体准确率，却不能保障数学、法律或低资源语言这些真正影响配方的桶。标注协议必须与本体版本绑定，分歧样本由仲裁产生可复用解释。

模型可以使用稀疏文本特征、小型编码器或蒸馏后的轻量模型。选型依据是每 Token 成本、吞吐、可校准性和切片质量，不是参数越多越好。批处理时保存模型摘要、输入规范化版本和置信度，便于新分类器上线后做差分。

### 4.4 层级分类减少不可能错误

先判断大类，再在父类内部判断子类，可以减少把法律文档直接判成源代码等离谱错误，也允许不同父类使用不同特征。但层级模型存在错误传播：父类错了，子类永远没有机会修正。因此应保留全局候选分数，并对低置信父节点允许回退到扁平分类或人工复核。

层级概率要注意条件关系。若 $P(parent)=0.6$，在父类内部 $P(child|parent)=0.9$，则子类联合概率是 $0.54$，不能把 0.9 直接当作全局置信度。发布系统应统一概率语义，避免不同模型的分数被错误比较。

### 4.5 多标签概率比硬标签更适合预算分析

一篇跨学科论文可以给物理 0.6、数学 0.3、计算机 0.1。库存统计时可以按软质量分配 Token，训练时再选择主桶或以确定性随机方式分配，避免同一文档被重复计入多个桶。软标签能表达边界不确定性，也让配方对分类器小幅变化更平滑。

但是软标签并不自动真实。未校准的神经网络可能对错误预测非常自信。必须用可靠性曲线、期望校准误差、类别条件校准和拒识质量验证概率。长尾类别尤其不能只看总体校准。

### 4.6 拒识与人工复核要按价值调度

不是所有低置信样本都值得人工看。可以定义复核价值：样本 Token 量、目标桶稀缺度、预测不确定性、来源风险和对预算的潜在影响。优先复核会显著改变小领域库存或触发治理决策的对象。大量低价值未知网页可以保持未知，而不是消耗标注预算。

人工结论进入金标集，并记录分类器是否因此改变。若复核只修正当前对象而不改进规则或模型，系统会永远重复同类工作。主动学习应设置独立验证集，避免把选择偏差带入质量评估。

## 5. 分类质量如何传导到采样

### 5.1 总体准确率不是关键指标

小领域高权重会加快重复曝光，需报告实际重复次数。

假设通用网页占百分之九十五，分类器把所有样本都预测成通用类，也有百分之九十五准确率，却会完全抹掉数学与代码。应查看每类 Precision、Recall、混淆矩阵、宏平均指标、按 Token 加权指标以及对最终预算的偏差。

采样系统更关心估计库存 $\hat N_i$ 与真实库存 $N_i$ 的误差，以及错分后各领域实际消费比例如何变化。一个小类百分之十的召回损失，可能比大类百分之一的错误更伤能力，因为小类本就只有极少预算。

### 5.2 用混淆矩阵做预算压力测试

设分类器混淆矩阵 $C_{ij}=P(\hat y=j\mid y=i)$。给定真实分布向量 $q$，预测桶分布约为 $\hat q=qC$。配方按预测桶给权重后，可以模拟真实领域获得的期望预算。这样能看到“计划给数学百分之十，实际只有百分之六，其余来自误判网页”的风险。

不要直接用矩阵求逆修正全部权重。长尾类别下矩阵估计噪声大，逆矩阵可能产生负数和极端权重。更安全的做法是构造置信区间、保守下界和场景压力测试，再通过抽样审计与代理训练验证。

### 5.3 标签漂移要与库存漂移分开

新批次的领域占比改变，可能因为世界数据真的变了，也可能因为分类器、规范化或解析器改变。发布报告同时固定旧分类器评估新数据、用新分类器重评稳定基准，并对交叉组合做差分。只有这样才能归因。

若线上分类器自动更新而训练配方不变，等价于悄悄改变了数据分布。分类器升级必须像过滤策略一样走 Shadow、差分、审批和版本发布，不能作为普通模型服务无感滚动。

## 6. 基础采样策略

### 6.1 按自然比例采样

令 $p_i=q_i$ 最简单，几乎不需要重复小领域，也最接近数据湖的自然分布。它适合作为基线和超大通用领域，但不能保证产品关心的能力。自然比例还会把采集偏差当成世界分布，例如爬虫覆盖率高的网站被过度代表。

自然采样的价值在于提供对照。如果一个复杂配方没有超过自然基线，团队需要解释额外偏置和系统成本是否值得。不要在没有基线的情况下将任何手工权重称为优化。

### 6.2 均匀领域采样

令 $p_i=1/K$ 能显著抬高小领域，但会让库存极小或质量不足的桶被反复曝光。它也默认每个本体叶子同等重要，而本体拆分方式会任意改变预算：把科学拆成十个子类后，科学总权重会无意增长。

均匀采样可用于短期诊断，让每个桶都获得足够梯度以测量能力，但通常不适合作为大规模最终配方。使用时必须设置曝光上限和叶子聚合规则。

### 6.3 温度采样

常用方法是对库存比例做幂变换：

$$p_i(\alpha)=\frac{q_i^\alpha}{\sum_j q_j^\alpha}$$

当 $\alpha=1$ 时回到自然比例；当 $\alpha=0$ 时得到领域均匀；$0\lt \alpha\lt 1$ 会平滑分布，提升小领域。也有实现使用温度 $T$ 并令指数为 $1/T$，所以配置必须写清公式，不能只写“temperature=2”。

温度采样只有一个自由度，易解释且适合建立基线，但无法表达某个领域的业务优先级、质量差异和许可成本。两个库存相同的桶会得到同权重，即使一个是高质量数学、另一个是低质量论坛。实践中温度结果通常还要乘领域先验，再归一化。

### 6.4 先验乘幂配方

给每个领域业务或质量先验 $a_i>0$，定义：

$$p_i=\frac{a_i q_i^\alpha}{\sum_j a_j q_j^\alpha}$$

$a_i$ 能表达同规模领域的不同价值，$\alpha$ 控制库存不平衡的平滑程度。所有参数都应版本化，并在报告中展示从 $q_i$ 到未归一化分数再到 $p_i$ 的完整计算，防止一个隐藏倍数改变训练。
