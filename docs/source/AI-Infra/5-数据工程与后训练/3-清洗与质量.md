# 清洗与质量：规范化、启发式过滤与模型化评分

「这条数据质量高不高」是一个没有单一答案的问题。工程上能做的，是把质量拆成可观测的维度，把决策拆成可解释的门禁，把「删了多少」拆成可复现的统计。

## 1. 质量是一组条件向量，不是一个自然常数

<div align="center">
  <img src="https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiinfra_y5_l09_01.png" width="78%" alt="启发式质量过滤" />
  <p>图 1：硬门禁、软分与灰区三层决策，规则必须带适用域与原因码</p>
</div>

$$
Q(d,u) = \left[q_{read},\ q_{structure},\ q_{information},\ q_{language},\ q_{diversity},\ q_{task}\right]
$$

文档 \(d\)、用途 \(u\)：可读性、结构完整、信息密度、语言一致、多样性、任务适配**可能互相冲突**。教育文章在知识任务上高分，口语对话在交互任务里更重要；高结构化列表不适合普通语言建模，却适合实体学习。

工程上可以为某个 Release 定义组合策略，但**必须保留原始特征**——只存组合后的单值，等于把「为什么判它差」抹掉了。

## 2. 三层决策

| 层 | 用途 | 例子 |
|---|---|---|
| 硬门禁 | 证据强、误伤代价已验证 | 空文本、严重解码损坏、超资源上限、几乎全是单一标点 |
| 软分 | 连续权衡 | 长度、平均词长、句子比例、重复度、停止词覆盖 |
| 灰区 | 阈值附近、规则冲突、新来源 | 进人工抽检或降权观察 |

一个典型决策顺序：先查 `invalid` 与 Policy → 少量 hard reject → 按 soft score 与不确定性分到 `accepted` 或 `gray`。

**软分不能豁免硬约束；排序还必须受覆盖预算限制。**

### 2.1 规则的逻辑形式

每条规则 \(r\) 应包含：适用域 \(A\)、特征函数 \(f\)、阈值区间 \(T\)、动作 \(a\)、原因码 \(c\)：

$$
r(d) =
\begin{cases}
a, & d \in A \land f(d) \in T, \\
\text{no-op}, & \text{otherwise}.
\end{cases}
$$

三个要点：

- **适用域**至少约束来源、语言、长度、`unit_type`、Recipe——同一阈值套到所有语言上必然出错；
- **动作不只是删除**：还可以标注、降权、隔离、请求更强评估；
- **冲突靠显式优先级与风险级别解决**，不能依赖配置文件里「恰好写在前面」。

## 3. 过滤本质是一个带预算的选择问题

$$
\max_{x_i \in [0,1]} \sum_i x_i V(d_i, u)
\quad \text{s.t.} \quad \sum_i x_i T_i \le B
$$

启发式特征只能**近似**价值 \(V\)，而且某些语言与领域会被系统性低估。所以不要「按一个分数从高到低截断」：

1. 先**分层保障覆盖**（语言、来源、内容类型各留最小预算）；
2. 层内再按质量与重复度采样；
3. 长尾语言、来源、类型设置 floor。

过滤与混合是两个阶段，但**画像必须给混合阶段留下足够维度**。

## 4. 误删比漏删更难恢复

漏过一些低价值文本只消耗 Token；**误删稀有高价值文本，可能永远失去覆盖**。

规则评审要分别估计 **false reject** 与 **false accept**，而不是只报 accuracy。在强不平衡数据上，一个「99% 准确」的规则仍可能误删大部分少数语言——因为它把「少数」当成了「异常」。

默认策略偏保守：**保留父资产**，先以灰区或采样降权观察下游影响，再决定是否硬删。

## 5. 数据画像：设阈值之前先理解分布

</div>

### 5.1 画像不是均值报表

平均长度、平均符号率很容易被极端值支配。可靠画像要给：**分位数、直方桶、零值率、缺失率、最大值、代表样本**，并按来源、抓取时间、语言、`unit_type`、解析器版本、权限域切片。产物绑定父 Manifest 与特征 Recipe，阈值决策才可复现。

### 5.2 基线 / 候选 / 差分

- **基线**：已发布版本；
- **候选**：新配方；
- **差分**：每个特征与状态的迁移（新增命中、旧命中消失、accepted→rejected、语言与来源切片变化、按采样权重折算的**暴露量**）。

差分不只看总体拒绝率，还要能回答「这批新被删的文档长什么样」。用稳定 Hash 抽样，保证评审者看的是同一批文档。

### 5.3 漂移只能提示「变了」，不能说明「坏了」

特征分布变化可能来自：真实内容变化、抓取源变化、解析器变化、过滤器故障。监控要同时看**输入画像与输出画像**，并保留 source cohort。

PSI、JS 散度、分位差适合当告警信号，但**告警后必须结合样本与上游版本判断**，不能自动把新分布拉回历史分布。

### 5.4 条件分布比全局分布更有用

中文、英文、泰文的字符/词比不同；代码与自然语言的标点率不同；标题与正文长度不同。全局阈值会把少数群体当异常。

应估计 \(p(feature \mid language, unit\_type, source\_class)\)，数据够时再加长度桶。低样本切片可用父层阈值或贝叶斯收缩，**但必须标记支持度**，不能靠几个样本定极端规则。

### 5.5 守恒关系

$$
\text{输入} = \text{accepted} + \text{gray} + \text{rejected} + \text{invalid} + \text{skipped}
$$

字符量也要满足同样的分解。**规则命中可以重叠，不能直接相加当拒绝总数**——要区分「独占最终原因」与「非独占 rule hit」。守恒断言失败时，整批画像不可用于发布决策。

## 6. 特征族：写清楚口径再定阈值

| 族 | 要点 |
|---|---|
| 长度 | 同时记 UTF-8 字节、Unicode 码点、字素簇、空白切分、目标 Tokenizer Token；**空白词数不能跨语言比较** |
| 行/段落/句 | 行数、非空行、段落、句子、最长行、行长分位、空行率；单行超长可能是换行丢失，逐词一行可能是错误 DOM 抽取 |
| 截断代理 | 括号引号平衡、末尾标点、代码围栏配对、解析器 `truncated` 标志——**更适合进灰区，不单独硬拒** |
| 列表密度 | 列表行比例、编号连续性、平均项长、链接密度；教程步骤与法律条款也是列表 |
| 结构多样性 | 行长变异系数、段落长度熵、标题正文比——模板页可能每段等长，OCR 错序又可能异常高 |
| 字符类别 | Unicode 类别比例 + replacement char + 私用区 + 不可见格式字符；分母必须是码点或字素簇 |
| 词形/停止词 | 每种语言独立词表与版本；**不支持的语言返回 `not_applicable`，绝不能按 0 分处理** |

## 7. 模型化质量评分：六条路线

<div align="center">
  <img src="https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiinfra_y5_l10_01.png" width="78%" alt="模型化质量评分" />
  <p>图 3：教师标签、分类器、参考语料、困惑度、密度比、集成各有适用边界</p>
</div>

| 路线 | 强项 | 边界 |
|---|---|---|
| 教师模型打标 | 能按复杂 rubric 输出分项与理由 | 继承模型偏好、提示敏感、知识盲区；必须固定教师版本/prompt/解码/截断，并做人工 Gold 抽检 |
| 编码器分类器 | 语义 + 局部结构，可多任务头共享 | 输入长度受限，需窗口策略；多任务冲突与校准更复杂 |
| 参考语料分类器 | 「像不像高质量参考集」 | 只代表参考分布；参考集偏百科/学术就会清掉口语与长尾 |
| 困惑度模型 | 便宜、可解释为「像不像该分布」 | 低损失可能流畅也可能重复；参考模型数据泄漏会压低已见文本 |
| 损失差 / DSIR | 判断「更接近目标域还是通用域」 | 适合**领域适配**，不是全局质量；密度比极端要裁剪 |
| 集成 | 提高稳定并估计分歧 | 成本高；成员相关错误不等于独立不确定性 |

困惑度的写法：

$$
L(d) = -\frac{1}{T}\sum_{t=1}^{T}\log p_\theta(x_t \mid x_{<t}),\qquad \mathrm{PPL} = e^{L}
$$

**PPL 是一个模型相对信号，不是质量温度计。**

## 8. 训练评分器时的八个陷阱

1. **来源匹配**：正例来自书籍、负例来自网页，分类器会学「来源/HTML 残留/长度」，不是质量。要在同来源、同语言、同类型、同长度桶内比较；
2. **先去重再划分**：近重复跨训练/测试会让指标虚高。先用精确/MinHash/语义簇建 `group_id`，再按组划分；
3. **域级划分**：只做随机划分无法测新站点泛化，至少要同时有 random holdout 与 domain holdout；
4. **时间划分**：新术语与站点模板持续变化，用较新时间窗做测试才能评估漂移；
5. **基准污染**：标签集、正例、领域词典不能包含目标基准原题或近似改写，否则选择器会定向偏好基准风格；
6. **长度与语言平衡**：分类器很容易用长度猜等级、用主流语言字形猜高质量；评估要画各桶可靠性；
7. **困难负例**：随机乱码太容易，教不会区分「流畅 SEO 文、事实空洞模板、答案缺失、表面专业的错误」；
8. **样本权重**：高置信/多人一致/专家标签高权重，弱监督/单教师/争议样本降权——**不能让权重只看模型自己的 confidence，形成自确认**。

## 9. 领域分类与难度

- **本体**：`science → biology → genomics`，标签要有定义、正反例、父子关系、Owner、版本；**别让部门组织结构直接变成本体**；
- **多标签损失**：

$$
\mathcal{L}_{domain} = -\sum_k w_k\left[y_k\log p_k + (1-y_k)\log(1-p_k)\right]
$$

标签缺失 ≠ 负例，需要 mask；稀有标签重加权后要重新校准。

- **开放集合拒识**：生产里总会出现本体外的新领域。最高 softmax 低只是一个信号，神经模型对域外仍会过度自信；可用能量、距离、集成分歧、原型，并保留 `other/unknown` 进人工发现流程；
- **层级评估**：错成同父兄弟与错到完全不同大类代价不同，除 micro/macro F1 还要报层级距离、父级召回、稀有标签 AP、多标签校准；
- **文档级聚合**：长文按窗口预测再按有效 Token/段落类型/置信聚合——**一个附录代码块不该把论文主域变代码**，一个医学免责声明也不该把商品页变医学；
- **本体漂移**：定期提出变更，新标签要回标代表数据、重训并提供新旧映射，**不能让历史 Mix 不可复现**。

## 10. 标签是不可变证据

每条标签绑定：`record_id`、`view_digest`、`rubric_version`、annotator/teacher、prompt、时间、confidence。

三条纪律：指南变化产生**新 Label Set**，不覆盖旧值；正文修改后旧标签**不能自动迁移**；训练 Manifest 精确列出用了哪些标签版本。

## 写在最后

清洗与质量的工程本质是**可解释的删除**：每条规则带适用域与原因、每次删除能被统计、每个评分器有版本与边界。
