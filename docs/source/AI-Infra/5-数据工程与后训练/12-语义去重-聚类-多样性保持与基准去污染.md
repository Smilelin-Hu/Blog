# 语义去重、聚类、多样性保持与基准去污染

## 1. 本文要解决的工程问题

向量聚类把表达同一事实的样本聚到一起，也把少数语言和稀有推理路径压成了小簇；若每簇只留一个，数据多样性会被算法主动抹平。

本文围绕一个可执行判断展开：怎样做语义去重与基准去污染，同时保住稀有能力和数据多样性？读完应能给出自己的系统边界、输入输出、版本关系和验收证据，而不是只复述工具名称或公式。

## 2. 本文交付物与判定标准

本文的核心决定是：把语义相似、能力覆盖、来源多样性和基准去污染分别建模，按用途选择降权、分层采样或阻断。

完成学习和实验后，应当交付一份最小可复现记录，至少包含输入快照、配置、代码版本、运行状态、原始输出和结论边界。验收证据是：聚类前后比较能力标签、语言、来源和长尾覆盖；去污染样本能够给出匹配片段和评测集版本。

围绕“语义去重、聚类、多样性保持与基准去污染”的验收不接受三类替代品：把模拟输出写成真实 GPU 结果；只展示成功样本而隐藏失败与 `SKIPPED`；只给总分，不保存能复算总分的对象级记录。

## 3. 前置知识与实验边界

“语义去重、聚类、多样性保持与基准去污染”的机制实验使用 Python 3.10 及以上版本和标准库，重点验证对象、算法或状态转换。真实硬件路径使用 PyTorch；检测不到 CUDA 时必须输出结构化 `SKIPPED`，不得静默改跑 CPU 后仍标成 GPU 实测。

嵌入距离受模型和阈值影响，不能把语义近邻自动等同于应删除对象。

### 3.1 业务背景与失败模式

精确哈希、MinHash 和子串去重可以识别同字复刻，却难以发现改写、翻译、模板换词、答案重述和语义高度重合。Embedding 与聚类把文档映射到语义空间，使相似但字面不同的样本可被发现；同时也带来新的风险：同主题不等于重复，少数表达常位于密集簇边缘，错误阈值会把观点、语言与文化多样性一起删掉。基准去污染还要求保护评测可信度，字符串 n-gram 只能覆盖直接复刻，释义、翻译和合成改写可能绕过。

本文建立一条完整主线：定义去重单位与等价关系，生成有版本的 Embedding，使用近邻检索与聚类构造候选，复核并生成 Duplicate Graph，以质量、来源、许可、时间和多样性约束选择代表；随后建立 Benchmark Registry 和多级污染检测，生成可审计的排除证据。实验包含 CPU 机制实验和通用 CUDA 真实向量批处理路径，硬件不足时返回 `skipped`，并学会在不夸大“语义相似”的前提下做生产发布。

### 3.2 语义相似

语义相似度衡量两个表示在某个编码器空间中的接近程度。它依赖模型、Pooling、截断、语言与归一化。相似可以因为主题相同、事实相同、风格相同或真正释义，不能直接等价“应该删一个”。输出应叫 similarity evidence，而不是 duplicate truth。

### 3.3 语义重复

语义重复是用途化判断：两个单元承载的信息与训练作用足够重合，在当前预算下保留一个代表更合适。它需要相似证据、结构、实体、数字、来源和人工或下游验证。新闻对同一事件的不同报道、同一公式的不同证明、同问题的不同好答案都可能相似但不重复。

### 3.4 聚类

聚类把数据组织成近似主题或密度群体，主要用于缩小比较范围、画像与多样性采样。K-Means 簇不是语义等价类，簇边界也随 seed、$K$ 和 Embedding 变化。SemDeDup 一类路线先用 Embedding 与聚类缩小搜索，再在簇内按相似阈值处理；工程上必须保存聚类 Artifact 与误差边界。

### 3.5 基准污染

污染是训练数据包含评测题、答案、解释或足以恢复评测目标的变体，使指标不能代表泛化。它的判断由 Benchmark Registry、时间、许可和评测 Policy 决定。与普通去重不同，污染通常不选择“质量更高代表”，而是把所有训练侧命中隔离或建立严格证据；评测资产本身权限更受控。

### 3.6 文档级

只有问题改写或只有答案复制时，单一文档哈希会漏检。

文档级适合文章、书章与完整网页，成本低且保持上下文。长文只部分重复时，整体 Embedding 会稀释；不同模板头尾也会干扰。需要与段落或窗口证据联合。输出保留 document group 和命中跨度，不能仅存代表 ID。

### 3.7 段落级

段落能发现转载片段、模板和答案复用，但删除后可能破坏上下文、指代和结构。段落边界依解析 Recipe，过短段自然碰撞高。生产常先用段落语义重复作为文档风险与采样权重，而不是直接剪掉所有匹配段。

### 3.8 句子级

句子适合基准题、问答、翻译与短声明。自然常识句大量重复，误删成本高。需要最小信息量、实体数字一致和上下文验证。句切错误会产生伪匹配，segmenter 版本进入 Artifact。

### 3.9 问题—答案对

只比较问题会把同题不同解法聚在一起，只比较答案会把通用短答碰撞。可分别编码 question、answer 和 explanation，再按用途组合。基准污染通常问题高相似加关键答案/选项一致更可信。SFT 去重则可保留不同正确响应的多样性。

### 3.10 滑动窗口

长文按固定 Token 窗口与重叠步长编码，能发现局部复刻，成本和候选量显著增加。窗口必须保持父跨度、Tokenizer 与截断状态。相邻窗口天然相似，要在同文边缘过滤。聚合到文档时区分单窗命中与大面积覆盖。

### 3.11 多模态单元

图文、表格问答和代码说明需要联合表示。只看文本会把不同图片同 caption 误判，或漏掉同图不同改写。多模态 Embedding、感知哈希和结构 ID 可联合。许可和删除仍以原资产为单位。纯文本部分只提供接口边界，不宣称覆盖视觉语义。

## 4. Embedding 系统

### 4.1 编码器选择

选择依据语言覆盖、领域、最大长度、推理成本、许可和可复现性。通用句向量适合短语义，多语模型支持跨语言释义，代码/数学需要专用表示。模型排行榜不能替代目标重复 Gold。一个编码器可能按主题聚类很好，却无法区分数字或否定。

### 4.2 Pooling 与归一化

CLS、mean、attention 或最后 Token Pooling 产生不同空间。余弦相似通常先做 L2 归一：

$$\hat e_i=\frac{e_i}{\|e_i\|_2},\qquad sim(i,j)=\hat e_i^T\hat e_j$$

零向量、NaN 与极短输入必须有状态。归一化在 FP32 完成并验证范数。Embedding Artifact 包含 Pooling 和 dtype。

### 4.3 长文本策略

首窗便宜但偏导语，均匀多窗覆盖更好，层级模型成本高。可为文档保存多个 window vector 与一个聚合 vector。近邻先用聚合召回，复核用窗口最大与覆盖。partial 状态不能被叫完整语义表示。

### 4.4 多语言空间

跨语言模型可发现翻译与释义，但语言间相似度尺度可能不同。分别构建同语和跨语 Gold，按语言对校准阈值。实体、数字和专名在翻译中变化需额外证据。模型不支持语言时返回 unsupported，不使用乱码向量。

### 4.5 数字与否定

“增长 10%”与“下降 10%”、“剂量 5mg”与“50mg”在语义空间可能很近，却不能当重复。复核层比较规范化数字、单位、实体、否定和代码字面量。冲突时保留两者或进入 gray。高余弦只表示候选。

### 4.6 Embedding 版本

模型、维度和归一方式不同的向量不能任意混查。

权重、Tokenizer、Pooling、窗口、归一、dtype 和代码由一个 digest 标识。模型升级需要同父数据近邻与 cluster 迁移，旧 cluster 不可直接混入新向量。向量表主键绑定 view digest，正文变化触发重算。

## 5. 候选生成与近邻检索

### 5.1 全对比较为何不可行

$N$ 条记录的全对为 $O(N^2)$，万亿规模不可接受。先按语言、类型、粗领域或 K-Means 分桶，再用 ANN 查 Top-K 候选。分桶提升效率但可能漏跨桶重复，因此保留边界探测与跨语言专用路径。召回评测必须在人工 Gold 上完成。

### 5.2 K-Means 粗分

K-Means 最小化到质心平方距离：

$$\min_{C,\mu}\sum_i\|e_i-\mu_{c_i}\|_2^2$$

对归一向量可用球面近似。$K$ 决定簇大小和漏召，seed 影响边界。聚类用于候选缩减，不把 cluster_id 当永久主题。保存质心、分配与训练样本摘要。

### 5.3 ANN 索引

HNSW、IVF、PQ 等在内存、构建、召回和更新上权衡。索引参数、库版本、训练向量和 seed 写入 Artifact。Top-K 过小漏密集簇，过大候选爆炸。使用小规模精确近邻评估 Recall@K，并按语言类型切片。

### 5.4 候选对去重

相似不等于重复，矛盾答案也可能有很近的向量。

近邻 A→B 与 B→A 会重复，规范化 pair key 为 (min_id,max_id)。同父文档相邻窗口按规则排除。候选表包含相似度、rank、索引版本和召回路径。不同路径命中可以合并证据但不丢来源。

### 5.5 二阶段复核

第一阶段高召回 Embedding，第二阶段用 cross-encoder、n-gram、实体数字、结构和教师判断提高精度。复核成本只作用候选。每级阈值和 abstain 保留。端到端指标以全 Gold 对为分母，不能只在第一阶段已召回的容易集合报告。

## 6. Duplicate Graph 与聚类语义

### 6.1 图模型

把主题聚类直接当去重会删除互补事实。

记录为节点，高置信重复为边，连通分量形成候选组。相似关系未必传递：A 像 B、B 像 C，不代表 A 像 C。简单连通会产生链式过合并。可限制直径、要求代表邻接、使用 complete-link 近似或在分量内二次切分。

### 6.2 阈值图

同一相似度在不同切片中未必有相同误删率。

边条件 $sim\ge t$ 看似简单，但阈值依语言、长度和类型。保存 raw score 与 Policy，允许重放不同 $t$。阈值附近进入 gray，不直接加边。图版本绑定候选与复核 Artifact。边删除或新增产生新 Graph Release。

### 6.3 社区与密度

主题簇可用社区或密度算法，但它们的簇不是重复等价类。密集区域通常冗余高，也可能是重要高频概念。用簇大小和局部密度做采样，而非全删到一个。噪声点可能独特也可能错误，需质量证据。

### 6.4 增量图

新数据查询旧索引和本批，生成新边；旧节点代表与策略变化可能需要重算。不能只把新记录与代表比较，若代表丢失细节会漏匹配。周期性全量或分区重建保证质量。Graph Manifest 记录 base 和 delta。

### 6.5 跨版本稳定 ID

cluster_id 可能重排，不适合作为永久主键。可用成员 record_id 规范摘要形成 group fingerprint，但成员变化会改变。资产目录保存 old→new overlap 映射，消费方依 Release。不要承诺跨算法同 cluster ID。

## 7. 代表选择与多样性

### 7.1 代表不是随机删剩

仅选离中心最近的对象可能消除边缘但有价值的样本。

组内代表可按许可、质量、来源权威、文本完整、时间、语言、格式和下游价值排序。排序分项保存。若代表后来退出，能够选择次优而无需恢复已销毁文本。所有成员关系保留在受控映射中。

### 7.2 Pareto 选择

高质量与多样性、短成本与完整性可能冲突。不要把所有维度随意加权成单分，可保留 Pareto 前沿，再由用途 Mix 选择。组内多个观点、语言或解法可各留一个。去重预算是每组上限而非永远一条。

### 7.3 语言与方言保护

跨语言相似可能是翻译，同一事实的不同语言仍对多语言模型有价值。默认不跨语言删除，或按语言各留代表；平行语料用途甚至应保留成对关系。方言不能因靠近标准语 Embedding 就被吞并。报告语言保留矩阵。

### 7.4 时间多样性

同一新闻事件的后续更新包含新事实，最新版本不一定替代旧历史。比较时间、实体和事实差异，保留重要演进。软件文档则可能优先最新但历史版本对兼容有用。代表 Policy 按用途定义。

### 7.5 观点多样性

主题相似的评论、论证与分析可能表达不同立场。Embedding 容易把它们聚近。使用立场、实体关系、来源与反事实样本检测，组内按观点配额。质量筛选不能以“主流中心”清除边缘声音。

### 7.6 难度多样性

同概念的初学解释和高级证明语义相似，训练作用不同。结合难度、文体与结构，按课程保留多层。语义去重不能替代课程选择。代表表保存各难度候选，Mix 阶段再决定比例。

## 8. 基准去污染

### 8.1 Benchmark Registry

记录 benchmark_id、版本、split、题型、问题、选项、答案、解释、语言、发布日期、许可、保密级别和允许匹配方式。训练系统只获取受控指纹或服务接口，避免评测正文泄漏。任何新评测先注册再允许数据发布。

### 8.2 精确与 n-gram 层

规范化后检查完整题、关键长 n-gram、代码 Token 和答案片段，精度高且易解释。阈值考虑短题自然碰撞，问题与答案联合证据更强。保留命中跨度与 hash，受限环境不复制完整 benchmark。

### 8.3 模糊字符串层

编辑距离、MinHash、BM25 和最长公共子串发现轻微改写、格式变化与选项重排。数字、实体和代码标识符加权。对选择题，选项集合相似可作为证据。所有候选送更强层或隔离。

### 8.4 语义层

Embedding 与 cross-encoder 发现释义和翻译，但同知识不等于泄漏。结合发布日期、来源、答案与结构。公开研究已展示简单改写能绕过 n-gram，因此必须有语义层，同时也要承认它无法证明模型训练记忆。高风险基准阈值更保守。

### 8.5 生成式复核

教师可判断训练文本是否包含完成评测所需的同一问题与答案，输出结构化证据。成本与不确定性高，只处理候选。固定模型、Prompt 和版本，人工复核关键命中。教师不能访问超出权限的评测正文。

### 8.6 时间证据

训练抓取早于评测创建通常降低直接污染可能，但评测可能来自更早公开题库，发布日期也不等于内容首次出现。时间只是证据，不单独放行。建立 source provenance 与题目谱系。合成评测可能复述训练数据，方向更复杂。
