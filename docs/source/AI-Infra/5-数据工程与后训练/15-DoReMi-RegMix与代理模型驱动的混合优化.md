# DoReMi、RegMix 与代理模型驱动的混合优化

## 1. 本文要解决的工程问题

代理模型在短预算上给出一组最优混合，放大到目标模型后排名反转。原因可能来自规模、Tokenizer、训练步数或能力进入学习曲线的时间不同。

本文围绕一个可执行判断展开：怎样用代理训练优化数据混合，并识别 DoReMi、RegMix 与动态方法的外推边界？读完应能给出自己的系统边界、输入输出、版本关系和验收证据，而不是只复述工具名称或公式。

## 2. 本文交付物与判定标准

本文的核心决定是：把 DoReMi、RegMix 和代理搜索当作候选生成器，使用多预算、多种子和外推检查决定是否采用。

完成学习和实验后，应当交付一份最小可复现记录，至少包含输入快照、配置、代码版本、运行状态、原始输出和结论边界。验收证据是：候选配方共享训练预算和评测切片，报告代理排名稳定性、外推误差与目标模型复验。

围绕“DoReMi、RegMix 与代理模型驱动的混合优化”的验收不接受三类替代品：把模拟输出写成真实 GPU 结果；只展示成功样本而隐藏失败与 `SKIPPED`；只给总分，不保存能复算总分的对象级记录。

## 3. 前置知识与实验边界

“DoReMi、RegMix 与代理模型驱动的混合优化”的机制实验使用 Python 3.10 及以上版本和标准库，重点验证对象、算法或状态转换。真实硬件路径使用 PyTorch；检测不到 CUDA 时必须输出结构化 `SKIPPED`，不得静默改跑 CPU 后仍标成 GPU 实测。

代理实验降低搜索成本，不能证明目标规模下的绝对最优。

### 3.1 业务背景与失败模式

前一篇解决了领域、权重、Token 预算和课程的执行问题，但没有回答“哪个权重更好”。人类可以根据库存、产品目标和经验提出合理候选，却很难直觉处理几十个领域的非线性交互：提高代码可能帮助推理也可能伤害通用语言，提高网页可能增加多样性也可能引入噪声，小领域的高损失可能代表尚未学会，也可能代表不可学。

本文研究三类代理驱动方法。DoReMi 用参考模型定义领域超额损失，再以 Group DRO 训练代理模型，让权重聚焦于相对参考仍有学习价值的领域；RegMix 在多个配方上训练大量小代理模型，用回归器学习“配方到效果”的响应面，再搜索新配方；DoGE 等方法则从目标泛化与梯度关系估计领域权重。它们不是能自动发现永恒最优分布的按钮，而是把高成本大模型试错转换成低成本、可审计的实验设计。

本文的工程目标是建立代理实验平台：冻结领域和数据快照，生成覆盖混合空间的候选，公平训练代理，收集逐域损失与目标评测，拟合或在线更新权重，验证排序能否跨种子、模型规模和训练预算迁移，最后将候选编译成前一篇定义的正式配方。任何算法结论都必须经过库存、曝光、治理、污染和目标模型 Canary 门禁。

### 3.2 学习目标与能力清单

### 2.1 配方空间是单纯形

可行空间由数学约束与实际可用数据共同决定。

有 $K$ 个领域，混合向量 $p\in\Delta^K$，满足 $p_i\ge0$ 且 $\sum_i p_i=1$。训练过程记为 $M=A(p,D,B,s)$，其中 $D$ 是冻结数据快照，$B$ 是 Token 预算，$s$ 包含随机种子、模型和优化配置。评测函数 $J(M)$ 可能是验证交叉熵、下游能力、护栏或多目标组合。

真正希望求解的是：

$$p^*=\arg\min_{p\in\mathcal P} \mathbb E_s[J(A(p,D,B,s))]$$

其中 $\mathcal P$ 还包含保底、封顶、曝光、成本与治理约束。一次训练只观察一个高噪声点，领域数增加后搜索空间迅速扩大，因此需要代理模型与实验设计。

### 2.2 目标函数比优化器更重要

若目标只用平均验证损失，大领域或 Token 易预测领域会支配；若只用最差领域，极小噪声桶可能劫持优化；若用下游总分，评测权重和污染风险会进入配方。算法不能替团队决定价值。应先定义主目标、独立护栏和不可补偿红线，再选择 DoReMi 或 RegMix。

目标报告保留向量，不只保存加权标量。即使搜索使用标量，最终选择仍查看各领域、各能力和风险的 Pareto 关系。改变标量权重必须重做候选排序，不能把旧最优继续称为最优。

### 2.3 代理假设必须显式

代理方法隐含至少三个迁移假设：小模型上的配方排序能迁移到大模型；较短训练预算上的排序能迁移到长预算；代理评测目标与最终产品能力相关。每个假设都可失败，并需要桥接实验测量 Spearman 排序相关、Top-k 命中、后悔值和护栏一致性。

代理的价值不是参数小，而是便宜地覆盖更多配方。如果小代理的噪声大到排序接近随机，继续扩大候选数只会制造虚假精确。先验证信噪比，再扩展搜索。

### 3.3 实验准备与责任边界

### 3.1 单领域直觉忽略交互

领域交互使逐域排序不足以确定最终混合。

配方是组成数据。提高一个领域必然降低其他领域，效果取决于替代了谁。代码与技术书籍可能互补，数学与科学也可能共享表示；单独给每个领域打价值分无法表达交互。

### 3.2 高质量标签不等于边际价值

一个高质量领域可能模型已经掌握，追加 Token 边际收益低；一个中等质量的大型网页领域可能提供广泛词汇和世界知识。优化关注当前模型、预算和目标下的边际训练价值，不能把人工质量排序直接变成采样排序。

### 3.3 当前损失不等于应该上采样

高损失可能是难且有价值，也可能是噪声、Tokenizer 不适配或分布外乱码。低损失可能是已掌握，也可能是重复和模板泄漏。需要相对基线、学习动态、梯度迁移和独立验证，单一损失不能自动控制权重。

### 3.4 一次最佳结果可能是随机波动

预算有限时应优先核验关键候选，而不是追逐微小差距。

代理规模小、训练短时，不同初始化、数据顺序和评测样本带来显著方差。若从上百候选中挑最小观测值，会偏向噪声极端。多种子、交叉验证、候选复验和 Top-k 平均能降低赢家诅咒。

## 4. DoReMi 的核心直觉

### 4.1 为什么需要参考模型

比较要使用兼容 Token 口径，参考项用于估计可改善空间。

直接最小化最差领域损失会偏向本身熵高、噪声大或不可学的领域。DoReMi 先按参考分布训练一个参考模型，记录各领域参考损失。代理模型关注自己相对参考模型多出来的损失，而不是绝对难度。一个领域绝对损失高但已达到参考水平，不应持续吸走权重；另一个领域绝对损失低却明显落后参考，仍有优化空间。

### 4.2 超额损失

对样本 $x$ 所属领域 $i$，代理模型参数为 $\theta$，参考模型为 $\theta_{ref}$，可以定义 Token 平均超额损失：

$$R_i(\theta)=\mathbb E_{x\sim D_i} [\ell(\theta;x)-\ell(\theta_{ref};x)]$$

实际小批次估计会有噪声，可做非负截断、移动平均或其他稳定处理。实现必须明确是在样本、有效 Token 还是序列上平均，参考与代理使用相同 Tokenizer、Mask 和评估语义。

### 4.3 Group DRO 视角

代理训练可写成领域分布 $\alpha\in\Delta^K$ 与模型参数的极小极大问题：

$$\min_\theta\max_{\alpha\in\Delta^K} \sum_i \alpha_i R_i(\theta)$$

内层给当前超额损失大的领域更高权重，外层模型在该混合上更新。训练过程中领域权重随状态变化，最后把平滑后的平均权重作为目标大模型的静态重采样比例之一。

### 4.4 指数梯度更新

一种常见权重更新形式是：

$$\tilde\alpha_i^{t+1}=\alpha_i^t\exp(\eta\hat R_i^t),\qquad \alpha_i^{t+1}=\frac{\tilde\alpha_i^{t+1}}{\sum_j\tilde\alpha_j^{t+1}}$$

$\eta$ 是权重学习率。过大会让权重在噪声领域间跳跃，过小则几乎不离开初始分布。数值实现使用减去最大 Logit 的 LogSumExp 技巧，防止指数溢出。

### 4.5 平滑与最小概率

如果一个领域权重变为零，代理训练后续没有数据估计其超额损失，闭环无法自我纠正。可与均匀或参考分布混合：

$$\alpha'=(1-\epsilon)\alpha+\epsilon q$$

其中 $q$ 是探索分布。还可以设置每域下限和上限。探索不是算法装饰，而是保证观测覆盖、抵抗早期误判的重要条件。

### 4.6 为什么取时间平均

训练早期超额损失大、波动强，后期模型状态又与最终目标更接近。只取最后一步容易受单批噪声影响，只取全程简单平均又可能让早期主导。工程上比较全程平均、烧入后平均、指数移动平均和分阶段平均，并在桥接实验上选择，不把某个聚合当理论唯一答案。

### 4.7 两阶段工作流

阶段一训练参考模型并冻结；阶段二从同一初始条件或明确基线训练 DoReMi 代理，在线更新领域权重并记录轨迹；阶段三把聚合权重投影到生产约束，重采样完整数据，训练目标模型。参考和代理的成本必须计入优化总成本，不能只报告目标模型节省。

## 5. DoReMi 参考模型设计

### 5.1 参考分布代表比较基准

参考模型通常按某个基准分布训练，它决定“超额”相对于什么。使用自然分布、人工基线或当前生产配方会得到不同权重。参考不是客观世界，选择理由必须记录，并至少比较一个替代参考的敏感性。

### 5.2 参考模型必须充分但不必最强

参考太弱，所有领域超额损失都容易且不稳定；参考远强于代理，代理可能长期落后并偏向容量需求最大的领域。参考与代理的参数、训练预算、优化器可以相同或相近，关键是超额信号有区分度且能稳定迁移。

### 5.3 参考损失不能从训练批次泄漏

若参考模型在完全相同样本上过拟合，训练样本参考损失偏低，会放大超额。可以用冻结参考模型对代理批次前向，或预计算样本级参考损失；预计算节省算力但增加存储和版本耦合。无论哪种，都保证参考模型不随代理更新。

### 5.4 预计算与在线计算权衡

预计算每 Token 损失体积巨大，常保存序列级或文档级有效 Token 均值。若代理使用不同 Packing 或 Mask，聚合值可能不匹配。在线双前向计算简单准确，却增加 GPU 时间和显存。可以让参考模型无梯度、低精度运行，并 Profile 决定。

### 5.5 参考模型数据污染

参考训练数据与代理候选重叠是方法设定的一部分，但验证集、下游评测与盲测不能泄漏。若参考模型包含某领域评测答案，超额损失和最终验证都会被扭曲。证据包记录参考快照、去污染规则和评测摘要。

## 6. DoReMi 在线训练细节

### 6.1 领域批次与混合批次

为估计每域损失，可以轮流取领域纯净微批，也可以在混合批内按 Token 掩码聚合。纯净批次实现简单但改变梯度噪声和系统吞吐；混合批更贴近目标训练，却让小领域每步可能没有样本。选择方案要同时报告算法与性能影响。

### 6.2 缺失领域的更新

某步没有领域 $i$ 样本时，不能把其超额损失当零。可维持旧估计、使用移动平均，或按固定轮询窗口确保每域都被观察。大领域数下，按窗口更新比强求每步覆盖更现实。

### 6.3 Token 归一化

不同领域序列长度和 Mask 比例不同。领域损失按有效 Token 求和再除有效 Token 数，跨 Rank 先归并分子与分母，不能先平均每 Rank 损失再平均，否则不等批量会产生偏差。

### 6.4 负超额损失

代理可能优于参考，使超额为负。如果直接指数更新会降低该域权重，这符合“已超过基准”的直觉；若采用非负截断，则该域至少不因负值继续下降。两种处理改变优化目标，必须依据实现与实验记录，不能混称同一算法。

### 6.5 权重学习率与振荡

监控权重总变差、熵、最大桶和符号翻转。权重学习率过大时，领域在相邻窗口互相抢占；过小时，轨迹与初始分布几乎一致。可用较长损失窗口、烧入期、梯度裁剪和探索混合稳定，但每个措施都要做消融。

### 6.6 从动态轨迹导出静态配方

目标大模型通常消费固定配方，而 DoReMi 代理产生动态权重。导出时选择时间段，聚合权重，再投影到库存与治理约束。报告投影前后差异；如果多个关键领域因生产约束大幅改变，原代理结果已不再直接适用，应补代理验证。

## 7. RegMix 的核心工作流

### 7.1 把混合优化看成响应面建模

预测优配方仍需真实桥接验证。

RegMix 不在单次代理训练里在线更新领域权重，而是选择许多混合 $p^{(1)},\ldots,p^{(m)}$，分别训练代理模型，得到结果 $y^{(j)}$。再拟合函数 $\hat f(p)\approx y$，用廉价推断评估大量未训练候选，选择预测优秀且满足约束的配方。

这种方法把代理运行天然并行化，也能用非线性回归捕获领域交互。代价是需要足够覆盖的实验设计，并防止回归器在单纯形边缘外推。

### 7.2 设计混合样本

Dirichlet 分布是生成单纯形点的常用方法。浓度小会产生靠近顶点的稀疏极端混合，浓度大则集中在均匀附近。可以围绕自然或生产分布设置非对称参数，再混合多种浓度，以同时覆盖局部可行区和全局交互。

生成后要投影保底、封顶和曝光约束，并去掉过近候选。若先从无约束空间采很多点再大量拒绝，剩余设计可能集中在边界；应直接在可行域内设计或评估覆盖质量。

### 7.3 代理训练必须公平

所有候选对齐模型初始化策略、Token 预算、优化器、学习率、评测和数据质量。每个候选的实际消费必须通过 Token 账本验收。吞吐较慢的领域不能导致少训练 Token，否则回归器会把算力差异误当配方效果。

可以共享基础初始化以降低方差，但也会让结论只代表一个初始状态。更稳妥的是用区组设计：每个种子覆盖一组候选，模型中显式加入种子或批次效应，再对 Top 候选跨种子复验。

### 7.4 回归特征

最直接特征是 $K$ 个混合比例，但它们和为一，线性模型存在完全共线。可以去掉一个基准维度、使用对数比变换、加入二阶交互、熵、与自然分布距离、曝光和成本。树模型能学习非线性，却也更易利用设计偏差。

特征工程不能包含目标规模运行之后才知道的信息。若将代理终点损失作为特征去预测同一代理终点，可能表现很好却无法在新候选训练前使用。

### 7.5 回归目标

目标可以是某验证域损失、多个领域加权损失、下游能力或多任务向量。验证交叉熵便宜稳定，但与产品能力相关性需要验证；下游分数更直接但噪声与污染风险更高。多输出回归保留权衡，之后在预测 Pareto 前沿选候选。

目标方向和尺度要统一。不同任务分数可先转成相对基线改善或标准化，但标准化统计只用训练折，避免验证泄漏。

### 7.6 回归器选择

岭回归提供稳定线性基线，二次多项式能表达两两交互，树提升模型可表达复杂非线性。模型选择通过留出候选或嵌套交叉验证，不按训练集拟合优度决定。领域多、候选少时，复杂模型很容易记忆。

报告均方误差之外，更重要的是 Spearman 排序相关、Top-k 召回和选择后悔。配方搜索关心谁更好，而不是每个分数小数点预测是否准确。
