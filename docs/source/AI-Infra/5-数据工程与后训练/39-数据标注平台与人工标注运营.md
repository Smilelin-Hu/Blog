# 数据标注平台与人工标注运营

22 篇第 3.1-3.5 节讲标注协议（指南/盲化/平局/仲裁），34 篇第 7 节讲偏好标注质控；本文补协议之下的运营层：平台选型、任务分发、标注者资质与绩效、质检抽样、成本与产能模型。协议回答「怎么标才对」，运营回答「怎么让一群人持续标得对、标得起」。

## 1. 平台选型

| 平台 | 定位 | 适用 |
|---|---|---|
| Label Studio | 开源自托管，多模态模板 + ML backend 预标注 | 通用文本/图像/音频，数据不出域 |
| CVAT / doccano | 开源，分别偏视觉与文本 | 单一模态、预算有限 |
| 商业标注服务（Scale/Surge 类） | 平台 + 人力外包 | 峰值产能、专家标注（医学/法律/代码） |

LLM 后训练的特殊需求：pairwise 偏好比较 UI（双栏盲评、模型名隐藏，接 34 篇第 7 节的盲化协议）、长对话滚动上下文、多维评分（有用/诚实/无害分列）、标注者可见指南版本。自建平台时这些 UI 约束比通用标注工具更重要；数据敏感场景（含 PII 的偏好数据）优先自托管 + 脱敏后分发。

## 2. 任务分发与标注者资质

- **资质分层**：入门考试（gold 题集）→ 常规任务 → 专家任务（仲裁/高难样本）。资质按任务类型独立认证，代码标注资质不等于医学标注资质。
- **gold 题混入**：生产任务流中按比例（常见 5–10%）混入已知答案的 gold 题，实时估计每个标注者的准确率；gold 通过率跌破阈值自动暂停分发并触发复训。
- **动态路由**：难样本（模型分歧大、预标注置信度低）路由给高资质标注者；简单样本给新人练手兼产能。标注者画像记录速度、质量、擅长领域三个维度，**只按速度计件会系统性牺牲质量**，绩效必须质量加权。

## 3. 质控：一致性不等于正确性

- IAA（标注者间一致性）用 Cohen's κ（两人）/Krippendorff's α（多人、可处理缺失），按标签类别分别算——某类别 κ 低通常指向**指南歧义**而非标注者不认真，先修指南再谈处罚。
- 关键区分（2026 专家标注实践的共识）：**IAA 测一致性，不测正确性**——一群人可以一致地标错。正确性要靠专家 gold 标准与抽样复核，两者缺一不可。
- 质检抽样按 AQL（可接受质量水平）设计：批次抽样比例与拒收阈值预先声明，不合格批次整批返工而非只修抽到的错；争议样本走 22 篇第 3.4 节的仲裁流程，仲裁结论回流指南。
- 预标注（模型先标、人修改）能降成本，但引入锚定偏置——标注者倾向接受模型初稿。对策：关键任务一定比例盲标（无预标注）作对照，监控「修改率」异常偏低的小组。

## 4. 成本与产能模型

单条有效标注成本：$C_{label} = \frac{C_{hour} \cdot T_{task}}{Y_{pass}}$，其中 $T_{task}$ 单条耗时、$Y_{pass}$ 质检通过率。三个杠杆：预标注降 $T_{task}$（但盯锚定偏置）、培训与指南迭代升 $Y_{pass}$（一次性投入换长期良率）、路由优化让专家时间只花在难样本上。

产能规划要计学习曲线：新任务类型前两周产能按 50–70% 折算；指南每次大改视为新任务重新爬坡。偏好标注的成本单位是「一对比较」而非「一条样本」，与 34 的偏好数据预算口径对齐；RLVR 可验证任务尽量用自动验证替代人标（26 的口径），人标预算留给不可验证的主观质量。

## 5. 运营闭环与验收

标注运营的数据要回流：每批的 IAA、gold 通过率、返工率、单条成本进统一看板（33 的可观测性口径），指南版本与批次绑定——质量事故能追到「哪版指南、哪个小组、哪批任务」。标注者反馈（指南歧义上报）有闭环处理时限，否则一线会自行发明规则。

验收清单：资质认证与 gold 混入全覆盖、IAA 按类别达标且低分类别有指南修订记录、专家 gold 复核独立于 IAA、AQL 抽样方案预先声明、预标注锚定偏置有盲标对照、单条成本与产能看板按指南版本可追溯。
