# 新型推理工作负载基准平台

## 1. 工程目标

![项目全景](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiinfra_y3_l32_01.png)

*项目全景：从输入、关键组件到验收证据形成一条可回放路径。*

统一重放 reasoning、agentic、structured、multimodal 与 compound workload。项目按完整工程链验收：能够运行、采集证据、演示关键行为，并在故障后恢复。所有结果随输入、配置、环境和版本保存。

## 2. 知识范围

项目整合以下前序能力：《Reasoning LLM Serving：长思考与 Test-Time Scaling》《Agentic Inference：工具调用、Fan-out 与长会话》《Structured Output Serving：Grammar、FSM 与 XGrammar》《Multimodal Serving：Encoder、Media Cache 与异构流水》《Compound AI Serving：Embedding、Reranker、LLM 与工具链》。实现时允许复用已有模块，但必须重新验证跨模块接口、身份、截止时间、错误传播和观测字段。

## 3. 系统边界与架构

### 组件 1：Reasoning 任务集

Reasoning 任务集与 Agentic 任务图之间使用结构化合同。任务 ID、模型或策略版本随输入传入，输出附带配置摘要、时间、指标和错误，使隔离、回放和追踪拥有同一身份链。

### 组件 2：Agentic 任务图

Agentic 任务图接收带版本和任务身份的输入，并向结构化 Schema 集输出结构化状态。接口记录配置摘要、起止时间、核心指标与失败原因。客户身份和模型修订通过显式字段传递，便于故障回放和租户隔离。

### 组件 3：结构化 Schema 集

在这套架构中，结构化 Schema 集维护清晰的能力边界。输入携带任务及版本，输出由多模态输入集直接消费；运行记录包含配置、时间、指标和错误。租户与模型身份不放入不可见的全局状态。

### 组件 4：多模态输入集

多模态输入集负责处理已绑定任务和版本的输入，将可验证状态交给 Compound AI 编排器。组件对外提供配置摘要、开始结束事件、指标及失败原因，身份信息始终经过接口传播。

### 组件 5：Compound AI 编排器

Compound AI 编排器与统一证据采集器之间使用结构化合同。任务 ID、模型或策略版本随输入传入，输出附带配置摘要、时间、指标和错误，使隔离、回放和追踪拥有同一身份链。

### 组件 6：统一证据采集器

统一证据采集器接收带版本和任务身份的输入，并向 Reasoning 任务集输出结构化状态。接口记录配置摘要、起止时间、核心指标与失败原因。客户身份和模型修订通过显式字段传递，便于故障回放和租户隔离。

```python
"""Project 02 — heterogeneous inference workload replay platform."""

from __future__ import annotations

import argparse
import base64
import concurrent.futures
import hashlib
import json
import time
from collections import defaultdict
from pathlib import Path

from phase3lab.shared.http_client import auth_headers, discover_models, extract_text, metrics_evidence, request_json
from phase3lab.shared.runner import LabSpec, PreconditionError, run_cli
from phase3lab.shared.stats import latency_summary
from phase3lab.shared.workload import WorkItem, load_jsonl, replay

SPEC = LabSpec(
    lab_id="project-02-workload-platform",
    title="Project 02：Heterogeneous Inference Workload Benchmark Platform",
    goal="按到达时间重放 Reasoning、Agentic、Structured、Multimodal 与 Compound 五类工作流，并分别核算端到端 SLO。",
    real_evidence=("validated JSONL trace", "kind-specific execution graph", "subcall records", "arrival/dispatch timestamps"),
    required_inputs=("GPU-backed endpoint", "five-kind workload JSONL", "multimodal fixture"),
    outputs=("per-kind metrics", "SLO violations", "subcall lineage", "metrics snapshots"),
    acceptance=("all five handlers run", "arrival order is preserved", "structured output is validated", "compound/agentic paths make multiple linked calls"),
)

JSON_SCHEMA = {
    "type": "object",
    "properties": {"answer": {"type": "string"}, "confidence": {"type": "number"}},
    "required": ["answer", "confidence"],
    "additionalProperties": False,
}

def add_arguments(parser: argparse.ArgumentParser) -> None:
    parser.add_argument("--workload", default="data/project02_workload.jsonl")
    parser.add_argument("--time-scale", type=float, default=1.0)

def chat(base: str, model: str, prompt: str, max_tokens: int, call_id: str, *, response_format: dict | None = None, multimodal: list | None = None) -> tuple[dict, str]:
    content = multimodal if multimodal is not None else prompt
    payload = {"model": model, "messages": [{"role": "user", "content": content}], "max_tokens": max_tokens, "temperature": 0}
    if response_format is not None:
        payload["response_format"] = response_format
    started = time.perf_counter()
    status, body, _ = request_json("POST", f"{base.rstrip('/')}/v1/chat/completions", payload, timeout=240, headers=auth_headers())
    latency_ms = (time.perf_counter() - started) * 1000
    text = extract_text(body) if status == 200 else ""
    record = {"call_id": call_id, "status_code": status, "ok": status == 200, "latency_ms": round(latency_ms, 4), "input_sha256": hashlib.sha256(json.dumps(content, ensure_ascii=False, sort_keys=True).encode()).hexdigest(), "output_sha256": hashlib.sha256(text.encode()).hexdigest(), "output_chars": len(text)}
    return record, text

def reasoning(base: str, model: str, item: WorkItem) -> dict:
    record, _ = chat(base, model, item.prompt, item.max_new_tokens, f"{item.request_id}/reason")
    return {"ok": record["ok"], "subcalls": [record], "validation": {"handler": "reasoning"}}

def structured(base: str, model: str, item: WorkItem) -> dict:
    response_format = {"type": "json_schema", "json_schema": {"name": "benchmark_answer", "strict": True, "schema": JSON_SCHEMA}}
    record, text = chat(base, model, item.prompt, item.max_new_tokens, f"{item.request_id}/structured", response_format=response_format)
    findings = []
    try:
        value = json.loads(text)
        confidence = value.get("confidence")
        if set(value) != {"answer", "confidence"} or not isinstance(value.get("answer"), str) or not isinstance(confidence, (int, float)) or isinstance(confidence, bool):
            findings.append("schema_mismatch")
    except (json.JSONDecodeError, KeyError, TypeError):
        findings.append("invalid_json")
    return {"ok": record["ok"] and not findings, "subcalls": [record], "validation": {"handler": "structured", "findings": findings}}

def agentic(base: str, model: str, item: WorkItem) -> dict:
    prompts = [f"{item.prompt}\n分支 A：只找性能风险。", f"{item.prompt}\n分支 B：只找正确性风险。"]
    with concurrent.futures.ThreadPoolExecutor(max_workers=2) as pool:
        branches = list(pool.map(lambda pair: chat(base, model, pair[1], item.max_new_tokens, f"{item.request_id}/branch-{pair[0]}"), enumerate(prompts)))
    branch_records = [value[0] for value in branches]
    synthesis_prompt = "合并两条分支，明确冲突：\n" + "\n---\n".join(value[1] for value in branches)
    final_record, _ = chat(base, model, synthesis_prompt, item.max_new_tokens, f"{item.request_id}/synthesis")
    lineage = all(value[1] in synthesis_prompt for value in branches)
    return {"ok": all(record["ok"] for record in branch_records) and final_record["ok"] and lineage, "subcalls": branch_records + [final_record], "validation": {"handler": "agentic", "fan_in_lineage": lineage}}

def compound(base: str, model: str, item: WorkItem) -> dict:
    first, evidence = chat(base, model, "列出回答所需的三项证据：\n" + item.prompt, item.max_new_tokens, f"{item.request_id}/evidence")
    second_prompt = f"问题：{item.prompt}\n只根据以下证据回答：{evidence}"
    second, _ = chat(base, model, second_prompt, item.max_new_tokens, f"{item.request_id}/answer")
    return {"ok": first["ok"] and second["ok"] and evidence in second_prompt, "subcalls": [first, second], "validation": {"handler": "compound", "lineage": evidence in second_prompt}}

def multimodal(base: str, model: str, item: WorkItem) -> dict:
    image = Path(item.image_path)
    if not image.is_file():
        raise PreconditionError(f"multimodal image does not exist: {image}")
    raw = image.read_bytes()
    mime = "image/png" if image.suffix.lower() == ".png" else "image/jpeg"
    content = [
        {"type": "text", "text": item.prompt},
        {"type": "image_url", "image_url": {"url": f"data:{mime};base64,{base64.b64encode(raw).decode()}"}},
    ]
    record, _ = chat(base, model, item.prompt, item.max_new_tokens, f"{item.request_id}/vision", multimodal=content)
    return {"ok": record["ok"], "subcalls": [record], "validation": {"handler": "multimodal", "image_sha256": hashlib.sha256(raw).hexdigest(), "image_bytes": len(raw)}}

HANDLERS = {"reasoning": reasoning, "structured": structured, "agentic": agentic, "compound": compound, "multimodal": multimodal}

def execute_item(base: str, default_model: str, item: WorkItem) -> dict:
    handler = HANDLERS.get(item.kind)
    if handler is None:
        raise ValueError(f"unsupported workload kind: {item.kind}")
    model = default_model if item.model == "auto" else item.model
    started = time.perf_counter()
    result = handler(base, model, item)
    result.update({"request_id": item.request_id, "kind": item.kind, "model": model, "deadline_ms": item.deadline_ms, "end_to_end_ms": round((time.perf_counter() - started) * 1000, 4)})
    result["slo_pass"] = result["ok"] and result["end_to_end_ms"] <= item.deadline_ms
    return result

def fixture(args: argparse.Namespace) -> dict:
    kinds = list(HANDLERS)
    records = [{"request_id": f"fixture-{kind}", "kind": kind, "handler": HANDLERS[kind].__name__, "subcall_count": 3 if kind == "agentic" else 2 if kind == "compound" else 1} for kind in kinds]
    return {"handlers": records, "all_kinds_distinct": len({item["handler"] for item in records}) == len(kinds), "arrival_replay": True}

def real(args: argparse.Namespace) -> dict:
    if len(args.base_url) != 1:
        raise PreconditionError("provide exactly one --base-url")
    workload = load_jsonl(args.workload)
    kinds = {item.kind for item in workload}
    missing = sorted(set(HANDLERS) - kinds)
    if missing:
        raise ValueError(f"workload does not exercise handlers: {', '.join(missing)}")
    served = discover_models(args.base_url[0])
    model = served[0] if args.model == "auto" else args.model
    if model not in served:
        raise PreconditionError(f"model {model} is not served")
    before = metrics_evidence((args.evidence_url or args.base_url)[0])
    records = replay(workload, lambda item: execute_item(args.base_url[0], model, item), concurrency=args.concurrency, time_scale=args.time_scale)
    after = metrics_evidence((args.evidence_url or args.base_url)[0])
    groups = defaultdict(list)
    for record in records:
        groups[record["kind"]].append(record)
    per_kind = {}
    for kind, values in groups.items():
        per_kind[kind] = {
            "requests": len(values),
            "slo_pass": sum(item["slo_pass"] for item in values),
            "success": sum(item["ok"] for item in values),
            "latency": latency_summary([item["end_to_end_ms"] for item in values]),
            "subcalls": sum(len(item["subcalls"]) for item in values),
        }
    return {
        "model": model,
        "workload": {"path": args.workload, "sha256": hashlib.sha256(Path(args.workload).read_bytes()).hexdigest(), "items": len(workload)},
        "metrics_before": before,
        "metrics_after": after,
        "per_kind": per_kind,
        "records": records,
        "acceptance": {"all_handlers_exercised": set(per_kind) == set(HANDLERS), "all_requests_succeeded": all(item["ok"] for item in records), "all_slos_met": all(item["slo_pass"] for item in records)},
    }

def main() -> None:
    run_cli(SPEC, add_arguments, real, fixture)

if __name__ == "__main__":
    main()
```

## 7. 真实本地路径

真实工作流直接执行“按到达时间重放 Reasoning、Agentic、Structured、Multimodal 与 Compound 五类工作流，并分别核算端到端 SLO。”。运行输入为 `GPU-backed endpoint`、`five-kind workload JSONL`、`multimodal fixture`；报告必须保留 `validated JSONL trace`、`kind-specific execution graph`、`subcall records`、`arrival/dispatch timestamps`。只有 `source=measured` 可以支撑性能或发布结论，`source=fixture` 只验证控制逻辑。

## 8. 工作负载与指标

### 指标 1：correctness

《新型推理工作负载基准平台》把 correctness 作为一项可重算指标，而非单独结论。报告保存原始事件、口径、单位、分母与时间窗口，并同步检查输出正确性、服务等级和故障恢复。

### 指标 2：latency

latency 随《新型推理工作负载基准平台》的原始事件保存，并注明定义、单位、采集点、时间窗口和分母。验收器可以重新计算聚合值；候选若以正确性、服务等级或恢复能力为代价，即使 latency 改善也不通过。

### 指标 3：throughput

项目为 throughput 记录计算口径、单位、分母、采集位置和窗口。报告中的聚合值能够从《新型推理工作负载基准平台》事件重算，并与正确性、SLO 及故障恢复一同验收。

### 指标 4：reliability

评审 reliability 时使用《新型推理工作负载基准平台》当前运行的原始数据。定义、单位、采集点、时间范围和分母全部随报告提供；任何以错误率、服务等级或恢复退化换来的改善都被门禁拦截。

### 指标 5：cost_efficiency

《新型推理工作负载基准平台》把 cost_efficiency 作为一项可重算指标，而非单独结论。报告保存原始事件、口径、单位、分母与时间窗口，并同步检查输出正确性、服务等级和故障恢复。

## 9. 故障注入与诊断

### 故障 1：长思考挤占短请求

本场景复现“长思考挤占短请求”。验收器检查发现时间、隔离范围、降级结果、回滚目标与恢复节奏，并用任务、制品、配置和负载定位根因。只有缓存、队列、资源及在途任务稳定后才算恢复完成。

### 故障 2：工具 Fan-out 形成调用风暴

主动制造“工具 Fan-out 形成调用风暴”，记录检测、隔离、降级、回滚和渐进恢复。排查时核对《新型推理工作负载基准平台》任务身份、制品摘要、配置及负载，再沿组件事件定位故障。重新导流前确认在途任务、缓存、队列与资源稳定。

### 故障 3：Grammar 编译造成首请求尖峰

“Grammar 编译造成首请求尖峰”由故障注入器稳定复现。系统需要给出告警、影响隔离、可解释降级和回滚事件；诊断依据任务 ID、制品摘要、配置、工作负载与组件时间线。进程恢复后仍要检查队列、缓存和在途任务。

### 故障 4：媒体阶段阻塞端到端链路

在《新型推理工作负载基准平台》中注入“媒体阶段阻塞端到端链路”后，观察故障发现、隔离、降级、回退与恢复导流。证据链从任务身份和制品版本开始，经过配置、负载与组件事件，最后确认资源和在途工作回到稳定状态。

## 10. 验收阈值

- 五类负载共享统一任务身份。
- 质量、延迟与成本口径分别可计算。
- 超时与取消传播到全部子阶段。
- 缺失媒体或工具时产生可解释降级。
- 指标可复现。
- 故障注入产生预期告警或降级。
