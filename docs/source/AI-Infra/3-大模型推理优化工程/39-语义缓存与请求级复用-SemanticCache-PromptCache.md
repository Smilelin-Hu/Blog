# 语义缓存与请求级复用：Semantic Cache 与 Prompt Cache

18 讲引擎内 prefix/session/KV locality 复用，主题二 25 §7 讲 automatic prefix caching；本文补应用层语义缓存：相似度命中、阈值与误命中风险、失效与租户隔离、命中经济性。边界先划清：prefix/KV 复用是**精确、无损**的；语义缓存是**近似、有损**的，风险等级不同，治理也不同。

## 1. 两类复用：无损 vs 有损

| 维度 | prefix/KV cache | semantic cache |
|---|---|---|
| 匹配 | token 精确前缀 | embedding 相似度 |
| 复用对象 | KV 状态（继续生成） | 完整答案（直接返回） |
| 风险 | 无（数学等价） | 误命中返回错答案 |
| 位置 | 引擎内 | 应用层 |

语义缓存流程：query embedding → ANN 检索 → 阈值判定 → 命中返回缓存答案 / 未命中走 LLM 并回写。量级对照：命中路径 3–8 ms vs 完整推理 500–2000 ms（2026 生产口径）。

## 2. 阈值与误命中风险

- cosine 阈值是最核心配置：调高命中率升、误命中也升——「相似但不同」的问题拿回错答案，比慢更伤。2026 实践共识：**precision 优先**，按场景分阈值，高风险场景（医疗/金融/权限相关）禁用或极高阈值。
- 误命中测量：near-miss 对抗查询对集合 + 在线抽样人评/judge 复核；误命中率进质量门禁（29 §6）。
- 投毒面：key collision attack（OpenReview 2025 证据）——攻击者构造语义近似 key 污染缓存，让后续用户命中恶意答案。缓存回写要鉴权、按租户隔离，匿名流量不回写或降权。

## 3. 失效、隔离与一致性

- **版本键**：模型版本、prompt 模板、租户策略进 cache key；升级批量失效，TTL + 事件驱动双通道。
- **租户隔离**：相似度检索不得跨租户（privacy-aware semantic cache，arXiv 2403.02694）；上线前跑对抗隔离测试，证明任何相似度分数都越不过租户边界。
- 一致性：缓存答案与新模型输出漂移靠版本键 + 质量门禁兜底；缓存不是「越久越省钱」，陈旧答案的隐性成本要计入。

## 4. 命中经济性与验收

净收益账：$h \cdot C_{infer} - C_{embed+ANN} - h \cdot p_{false} \cdot C_{wrong}$，其中 $h$ 命中率、$p_{false}$ 误命中条件概率、$C_{wrong}$ 错答案代价（客诉/事故）。break-even 命中率随 $C_{wrong}$ 上升而上升——**先估错答案代价，再定阈值**，顺序反了就会「省了推理钱、赔了事故钱」。

验收五项：命中率、误命中率、P99 附加延迟、租户隔离测试通过、经济性仪表盘（含负载率声明）。
