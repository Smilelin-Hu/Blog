# 多模态与扩散模型训练系统

主题一前序篇目围绕稠密 LLM 展开；本文补两类「非标准」训练负载：VLM 与扩散模型（DiT）。它们的并行、显存与数据管道各有特点，但工程纪律不变——先测量、再定位、一次只改一处。数据侧细节归主题五 38，serving 侧归主题三 14，本文只谈训练系统。

## 1. 负载特征：两种非标准训练

### 1.1 VLM：编码器-投影器-LLM 三段结构

视觉编码器（SigLIP/CLIP 系）把图像压成数百到上千 token；可变分辨率与任意宽高比使**视觉 token 数逐样本可变**，文本部分则与 LLM 同构。训练通常分阶段：投影器对齐预训练（编码器与 LLM 冻结）→ 多模态预训练/SFT（部分或全部解冻）→ 可选 RL。各阶段可训练参数集合与算力分布不同，并行策略要按阶段重估，而不是一套配置跑到底。

### 1.2 扩散 / DiT：训练单步、推理迭代

训练时采样 timestep $t$ 做**单步**噪声预测，没有推理时的迭代 rollout；计算图是 latent patch 上的纯 Transformer，LLM 的并行工具箱可复用。差异点在于：timestep/SNR 加权、EMA 权重副本、高分辨率 latent 带来的长序列（视频更极端）、图文对数据形态。

## 2. 数据与样本构造

- **VLM**：图像 token 预算与分辨率课程决定激活显存；packing 要按模态长度分桶，否则 padding 浪费算力；caption 质量决定能力上限（构造与去重见主题五 38）。
- **DiT**：aspect-ratio bucketing（SDXL 路线）减少 padding；多分辨率/多时长（视频）分桶；latent 由冻结 VAE **离线预提取并缓存**，避免每个 epoch 重复编码——VAE 编码是一次性成本，缓存后训练吞吐只算 DiT 本体。
- 两类负载共享数据供应链：分片、流式读取、去重与发布门禁，复用主题五 07/17 的链路。

## 3. 并行与显存

- **VLM**：编码器小、LLM 大，编码器 DP 或冻结、LLM 走 ZeRO/FSDP；解冻编码器时注意跨模态副本的梯度同步口径。长视觉序列可上序列/上下文并行（Ulysses/Ring，呼应 24）。
- **DiT**：FSDP/ZeRO + 激活重计算是基线；高分辨率/视频把 latent 序列切到多卡做序列并行，PipeDiT/PipeFusion 一类工作进一步把 SP 流水化、重叠通信。EMA 多一份权重副本，可放 CPU 异步更新。
- 显存账要单列：参数/梯度/优化器/激活/**EMA**/**latent 缓存**。BF16 + FP8 的数值路线与主题二 07/37 共用；梯度检查点用算力换显存，取舍看 MFU 实测。

## 4. 稳定性与效率

- **VLM**：模态不平衡 → 模态分组学习率与 loss 加权；loss spike 监控与处置呼应 20；分辨率渐进课程控制激活显存增长。
- **DiT**：timestep 采样（logit-normal 等）与 Min-SNR 加权稳定不同噪声档的梯度量级；EMA decay 与 v-prediction/ε-prediction 参数化影响高噪声档数值稳定性。
- 效率口径：VLM 用 samples/s 与图像 token 吞吐，DiT 用 latent tokens/s 与 MFU；**不要与 LLM 文本 token 口径混比**，否则容量规划全错。

## 5. 工程取舍与验收

| 决策点 | 选项 | 取舍 |
|---|---|---|
| 编码器冻结 vs 解冻 | 冻结省算力、解冻涨能力 | 按阶段切换，重估并行 |
| latent 在线编码 vs 离线缓存 | 在线省存储、离线省算力 | 多 epoch 必离线 |
| 纯 DP vs 序列并行 | DP 简单、SP 撑长序列 | 看单样本序列长与显存水位 |
| EMA 在 GPU vs CPU | GPU 快、CPU 省显存 | 看更新频率与带宽 |

- 验收：VLM 跑多模态基准 + **文本能力回归**（防灾难性遗忘，呼应主题五 18）；DiT 跑 FID/CLIP score + 人评抽样；性能一律单变量受控实验。
- 边界声明：本文不展开视觉语义算法细节，只覆盖训练系统；「不宣称覆盖视觉语义」的口径与主题五 12 保持一致。
