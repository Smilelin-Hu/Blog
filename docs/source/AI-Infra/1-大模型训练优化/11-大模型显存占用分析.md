# 大模型显存占用分析

### 0.1. 显存都去哪了：四大核心消耗源
在训练过程中，GPU显存主要被以下四类数据占据。以一个175B参数的GPT-3模型（FP32精度）为例，其显存总需求可超过**2000GB**。
1. **模型参数 (Model Parameters)**：模型的“大脑”本身，即所有网络层的权重和偏置。其显存占用 = **参数量 × 每个参数的字节数**。例如，70亿（7B）参数的模型在FP16精度下占用约14GB。
2. **梯度 (Gradients)**：反向传播时计算的参数更新方向，每一个模型参数都对应一个梯度值。其大小通常与模型参数**相等**。例如，7B模型在FP16精度下，梯度占用也约为14GB。
3. **优化器状态 (Optimizer States)**：显存消耗中最容易被低估的部分。以最常用的**Adam优化器**为例，它需要为每个参数额外存储**两个**FP32精度的状态（一阶动量`m`和二阶方差`v`），这使得**优化器状态的显存占用高达模型参数的4倍**（`2个状态 * 4字节/参数 = 8字节/参数`）。在典型的全量训练中，优化器状态消耗的显存占比高达**60%**。
**Adam优化器显存占用公式**：`优化器显存 = 参数量 × 2个状态 × 4字节 = 8 × 参数量(字节)`。
1. **激活值 (Activations)**：前向传播中每一层的输出结果，需要在反向传播时用于计算梯度。其占用与**批量大小（Batch Size）** 和**序列长度（Sequence Length）** 成正比，在实际训练中可占总显存的**30%**。
### 0.2. 混合精度训练下的显存占用计算
混合精度训练（如使用FP16/BF16）是目前大模型训练的标配，其显存占用规则如下：
- **模型参数**：以**半精度（FP16/BF16）** 存储和使用，每个参数占用**2字节**。
- **梯度**：同样以**半精度（FP16/BF16）** 存储，每个参数占用**2字节**。
- **优化器状态**：**始终以FP32精度**存储，以确保训练稳定性。若使用Adam优化器，每个参数占用**8字节**（`2个状态 × 4字节`）。
**显存占用“黄金公式”**
我们可以用一个通用公式来估算混合精度训练（使用Adam优化器）时的核心显存占用（即模型参数、梯度和优化器状态）：
**核心显存 ≈ 2Φ (参数) + 2Φ (梯度) + 8Φ (优化器) = 12Φ 字节**
其中 **Φ** 代表模型的参数量。这个公式清晰地表明，在混合精度训练下，模型参数、梯度和优化器状态三项的显存占用之和，大约是模型参数量的**12倍**。这个估算还未包含激活值和框架开销。
- **实战计算**：一个70亿（7B）参数的模型，其核心显存需求约为 `12 × 7B = 84GB`。此外，还需加上数量可观的激活值（可能达到几十GB）和约**5-10GB**的框架与CUDA上下文开销。
### 0.3. 使用 `nvidia-smi` 和 `nsys` 进行显存分析
有了理论，我们还需要工具来观测实际情况。
#### 0.3.1. `nvidia-smi`：命令行下的“快速体检”
`nvidia-smi`是NVIDIA官方的GPU管理和监控工具，能快速查看显存使用概况。
- **基本用法**：在终端输入 `nvidia-smi`。
- **主要信息**：输出表格会显示**显存总容量、已用容量、利用率**，以及每个进程的PID和显存占用。
- **常用技巧**：
- **实时刷新**：`watch -n 1 nvidia-smi` 可每秒刷新一次，便于观察动态变化。
- **查询进程**：`nvidia-smi pmon` 可查看每个进程的GPU利用率和显存使用情况。
- **结束进程**：`sudo kill -9 PID` 可清理因异常而残留的显存占用进程。
#### 0.3.2. `nsys` (NVIDIA Nsight Systems)：系统级的“深度CT扫描”
`nsys`是NVIDIA官方的系统级性能分析工具，能提供远超`nvidia-smi`的详细数据。
- **核心用途**：精确分析**CUDA kernel**执行、**内存拷贝**、**CPU/GPU**活动以及**显存分配**的详细时间线。
- **基本用法**：
1. **启动分析**：`nsys profile -o report_name python train.py`。
2. **查看报告**：使用NVIDIA Nsight Systems桌面应用打开生成的`.nsys-rep`文件。
- **进阶技巧**：
- **追踪内存**：添加 `--cuda-memory-usage=true` 参数可追踪CUDA内存的分配和释放。
- **精准采样**：使用`--capture-range`参数，可仅对训练脚本的特定步骤进行分析，减少数据量。
