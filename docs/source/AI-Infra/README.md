# AI Infra

以大模型系统为对象的基础设施笔记：训练优化、系统性能工程、推理优化、AI 平台工程、数据工程与后训练五个部分，关注「模型如何被装下、跑快、跑稳、跑得起」。

> 内容整理自本地课程讲义（`国产 GPGPU AI 推理优化工程师培养方案`配套课件），作为参考笔记。

## 内容结构

五个部分按工程对象分层：先是训练侧（并行、显存、通信），再是系统性能（硬件、Kernel、Runtime），然后是推理与平台（服务化、多租户、运维），最后是数据与后训练（数据、微调、对齐）。
