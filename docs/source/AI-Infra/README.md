# AI Infra

以大模型系统为对象的基础设施笔记，五个主题各成子系列：训练优化、系统性能、推理优化、平台工程、数据工程与后训练。主线是一条工程纪律——**先测量、再定位、一次只改一处、结果可复现**。

## 内容结构

五个主题按工程对象分层：先把模型训练起来（并行、显存、通信），再看系统性能（硬件、Kernel、Runtime），然后把它服务出去（推理引擎、网关、Fleet），接着把能力做成平台（K8s、调度、交付、运营），最后回到数据与后训练（语料、配方、偏好、RL）。

## 怎么读

- 只关心训练：主题一 → 主题二
- 做推理服务：主题三 →（缺平台能力时）主题四
- 搭数据/后训练链路：主题五 → 回到主题一看训练侧约束
- 做平台：主题四 → 主题三（服务侧需求）→ 主题五（数据侧需求）
